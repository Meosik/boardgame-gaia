# 1라운드 따라 하기 튜토리얼 — 요구사항·설계

작성: 2026-10-04 · 상태: 승인(2026-10-04) · 구현: Codex

## 1. 목표

설명을 읽게 하는 튜토리얼이 아니라, **실제 엔진 위에서 1라운드를 직접 두면서 게임의 모든 행동을 한 번씩
해보게** 한다. 매 단계마다 무엇을 할지, 어디를 누를지를 화면에서 짚어 주고, 플레이어가 그 행동을 실제로
해야 다음으로 넘어간다.

현재 상태와의 차이:

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 로비 "튜토리얼" | 행동 설명 읽기 페이지 | "1라운드 따라 하기" 시작 + 기존 설명 페이지 |
| 게임 중 "따라 하기" | 일반 게임 로그에서 8개 행동 체크만 | 전용 판에서 단계별로 이끌기 |
| 판 | 일반 게임 | 고정 시나리오(배치·자원 맞춤) |
| 상대 | 사람/AI | 정해진 수만 두는 스크립트 좌석 3개 |

## 2. 결정 사항 (2026-10-04 사용자)

1. **맞춤 시나리오** — 고정 시드·배치에 자원을 넉넉히 줘서 1라운드 안에 연방·가이아까지 전부 가능하게 한다.
2. **상대는 정해진 수만** — 대본대로 움직여 파워 충전처럼 상대가 있어야 하는 상황을 확실히 만든다.
3. **범위는 기본 + Lost Fleet 전부**. 고급 기술 타일(연구판 + Lost Fleet), 연방 토큰 뒤집기, 종료 점수 미리보기 포함(2026-10-04 추가).
4. 고정 설정(4인 + Lost Fleet)은 그대로 유지한다.

## 3. 시나리오 구성

- 서버가 정해진 시드로 판을 만들고, **배치가 끝난 1라운드 행동 단계** 상태로 바로 시작한다.
  종족 선택·초기 광산 배치·부스터 선택 과정은 건너뛴다. 이 과정은 단계 0의 설명 카드로만 짚는다.
- 플레이어 종족은 **테란**. 기본 규칙을 그대로 보여 주기에 가장 무난하다.
- 시작 부스터는 **부스터 8**(+3 거리 광산/가이아/함선 탐사 특수 행동)로 고정한다. 부스터 특수 행동을 체험하기 위해서다.
- 자원은 아래 대본을 끝까지 소화할 만큼 준다. 단계 0에서 "튜토리얼이라 자원을 넉넉히 받았다"고 알린다.
- **튜토리얼 전용 지급 (실제 규칙과 다름)**: 고급 기술 타일 2장에는 초록 연방 토큰이 2개 필요하다. 그래서 시작할 때
  **연방 토큰 1개(초록 면)를 미리 준다**(2026-10-04 사용자 결정). 추가 행동이 필요 없는 단순 보상 토큰으로 고른다.
  고급 타일 조건(트랙 4단계)을 맞추려고 시작 연구 단계를 올려 줄 때도 같은 방식으로 다룬다. 이런 지급은 단계 0 카드에
  "원래 규칙에서는 받지 않는 것" 목록으로 분명히 적는다.
- **자원 상한은 반드시 지킨다** (기본 룰북 p.9: "The track ends at 15, so you cannot have more than 15 ore, 15 knowledge,
  and 30 credits (15 per token)"; 엔진 `ORE_CAP`/`KNOWLEDGE_CAP`/`CREDITS_CAP`). 시작 상태를 직접 구성할 때도
  모든 좌석이 광석 ≤ 15, 지식 ≤ 15, 크레딧 ≤ 30이어야 한다. 파워 토큰과 QIC는 인쇄된 상한이 없지만, 실제 게임에서
  나올 법한 범위로 둔다(파워 토큰 합계는 종족 기본 + 대본상 필요한 만큼, 수백 개 금지). 자원이 모자라면 시작값을
  부풀리지 말고 대본 안의 자원 변환·파워 행동으로 채운다(2026-10-04 사용자 지적, 2차 구현의 광석 30·상대 지식 200은 위반).
- **상대는 필요한 수만 두고 일찍 패스한다.** 차례를 채우려고 연구를 반복하거나 자원을 부풀리지 않는다. 대본상 상대가 해야
  하는 수(A의 광산, B의 파워 행동 칸 선점 등)는 패스 전에 몰아서 둘 수 있다. 상대가 먼저 패스해도 플레이어는 혼자 계속 차례를 진행한다.
- 상대 3석은 "튜토리얼 상대 A/B/C"라는 이름의 스크립트 좌석이다. 실제 AI 드라이버는 돌리지 않는다.
- 정확한 좌표, 자원 수치, 맵 시드, 시작 연구 단계, 지급 토큰 종류는 구현 단계에서 **대본 전체를 엔진으로 재생해 통과하는 값**으로 정한다(§7 수용 기준).

**그 단계를 마친 직후** 상대 좌석이 두는 수다. 별도 표시가 없으면 상대는 아무것도 하지 않거나 이미 패스한 상태다.

규칙:

- 행성이나 함선을 골라야 하는 단계(1·7·11·15·17·18·19·20 등)는 **대본이 정한 대상만** 받는다. 다른 대상을 고르면 서버가 거절하고 대상을 다시 짚어 준다. 22·23단계의 타일 선택과 덮을 타일도 대본이 정한 것만 받는다.
- 22·23단계에서 "기술 타일을 얻는 행동"은 엔진이 허용하는 것(연구소/아카데미 업그레이드, 기술 타일 연방 토큰, 함선의 표준 기술 선택지 등) 중 대본이 가장 짧아지는 것으로 구현 때 정한다.
- 15단계(이전 안의 "공용 QIC 행동 칸")는 Lost Fleet 규칙과 충돌해 바꿨다. 확장 룰북 p.10 "6) Action: Power and Q.I.C. Actions — The Q.I.C. actions on the Research board are covered and thus cannot be used." 함선 QIC 행동은 21단계에서 체험한다.
- **26단계 종료 점수 미리보기**: 엔진의 `calculate_final_scoring_breakdown`을 25단계가 끝난 상태에 그대로 적용한 결과를 보여 준다. 실제로 게임을 끝내지는 않는다. 라운드 점수는 "매 라운드 목표 타일로 바로 받는다"는 설명 한 줄로 갈음한다.
- 마무리 카드에서 설명으로만 연결하는 것: 함선별 특수 보상 중 대본에 없는 것, 항법 5단계의 잃어버린 행성, 연구 5단계(초록 토큰 뒤집기), 테란 의회의 가이아 단계 전환, 다른 인원수에서 쓰는 Lost Fleet 조건판의 "25점" 면
  (Q1 결정, 2026-10-04: 미니 시나리오는 만들지 않음).
- 단계 수와 순서는 자원 흐름이 맞는 범위에서 구현 중에 조정할 수 있다. 다만 표에 있는 행동은 모두 넣어야 한다.

### 3차 보강 (2026-10-04 사용자 승인)

- **파워 받기 (2단계)**: 충전할 때 1→2→3구역으로 토큰이 옮겨지는 모습을 단계 카드에 그림으로 보여 주고, 파워 보드 세 구역을 강조한다.
  "충전량 − 1만큼 VP를 낸다"를 실제 숫자로 보여 준다. 충전(이미 있는 토큰 이동)과 토큰 획득(새 토큰이 1구역에 들어옴)의 차이를 한 줄로 설명한다.
- **자원 변환 (4단계 → 묶음)**: 파워→크레딧, 파워→광석, 파워→QIC, 광석→크레딧, 지식→크레딧 중 2~3가지를 연달아 해 본다.
  자원 상한 때문에 모자라는 광석을 파워→광석으로 채우는 장면을 여기서 자연스럽게 보여 준다. 끝에 전체 변환표 위치를 짚는다.
- **토큰 찢기 = 파워 태우기 (8단계)**: "3구역 파워가 모자라 다음 파워 행동을 못 한다 → 찢어서 채운다" 상황을 만들고, 바로 이어지는
  파워 행동 단계에서 그 파워를 쓰게 한다. 찢은 토큰은 게임에서 영원히 사라진다는 점을 짚는다.
- **패널 자동 열기**: 단계마다 대상이 있는 패널(우주 지도, 연구판, 함선 보드, 파워 행동판, 자유 행동 목록, 연방 화면)을 실제로 열어 준다.
  대상 요소가 화면에 없는 채로 강조만 하지 않는다.

## 5. 진행 방식

### 서버

- `POST /tutorial-games`가 튜토리얼 방을 만든다. 기존 `create_dev_game` 경로와 비슷하게 시나리오 `GameState`를 직접 구성하고, 방에 `tutorial` 상태(현재 단계 번호, 대본 id)를 붙인다.
- 플레이어 액션이 들어오면 **현재 단계의 목표 행동과 대상이 맞는지 먼저 확인**한다. 맞지 않으면 엔진에 넘기지 않고 `TutorialStepMismatch` 오류(현재 단계 안내 포함)로 거절한다. 맞으면 엔진이 평소대로 판정한다. 규칙 판정은 여전히 엔진이 한다.
- 단계가 끝나면 대본에 적힌 상대 수를 서버가 엔진에 순서대로 적용하고, 다음 단계로 넘어간다.
- 단계 번호는 방 상태에 저장하고 스냅샷에도 실어 보낸다. 새로고침하거나 재접속해도 같은 단계에서 이어진다.
- 튜토리얼 방은 로비 목록, 기보, 통계, AI 학습 데이터에 섞이지 않게 한다.
- 26단계에 도달하면 서버가 `calculate_final_scoring_breakdown`으로 플레이어별 종료 점수 내역을 계산해 튜토리얼 상태에 실어 보낸다. 게임 상태는 바꾸지 않는다.
- 대본 데이터(시나리오 생성 + 단계별 목표 행동/대상 + 상대 수)는 엔진 크레이트의 한 모듈에 둔다. 서버와 테스트가 같은 데이터를 쓰게 하기 위해서다.

### 프론트엔드

- 로비 튜토리얼 카드: **"1라운드 따라 하기"**(새 튜토리얼 방 생성)와 **"행동 설명 보기"**(기존 페이지) 두 버튼.
- 게임 화면에 **단계 카드**를 고정한다. 단계 번호/전체, 제목, 할 일 한 문장, 왜 하는지 한 문장. 실제로 해내면 "✓ 잘했어요" 결과 한 줄을 보여 주고 다음 단계로 넘어간다.
- **짚어 주기**: 그 단계의 대상 UI(행성 칸, 업그레이드 버튼, 연구판 칸, 파워 행동 칸, 함선, 자유 행동 버튼, 패스 버튼)를 강조 테두리로 표시한다. 필요한 패널(우주 지도, 연구·함선 등)은 자동으로 열어 준다. 대상 요소에는 `data-tutorial-target` 속성을 붙여 찾는다.
- 대본 밖의 행동은 화면에서도 막는다. 누르면 "지금은 ○○를 해 보세요" 안내를 띄운다. 서버의 거절과 같은 문구다.
- 상대가 수를 둘 때는 단계 카드에 "상대 A가 당신 광산 옆에 광산을 지었습니다 → 충전 기회" 식으로 무슨 일이 일어났는지 보여 준다.
- 26단계 카드는 서버가 보낸 종료 점수 내역을 항목별 표(최종 점수 타일 2개, 연구 트랙, 자원 환산, 그 밖의 항목, 합계)로 보여 준다. 4명 모두의 합계와 순위도 함께 보여 준다.
- 상단에 **처음부터 다시**(새 튜토리얼 방)와 **그만하기**(로비로) 버튼.
- 기존 "따라 하기" 체크리스트(일반 게임용)는 유지한다. 튜토리얼 방에서는 단계 카드로 대체한다.

## 6. 범위 밖

- 2라운드 이후 진행(마무리 카드 뒤로는 "로비로" 또는 "AI와 실제 게임 시작"만 안내).
- 다른 종족 튜토리얼, 경매/종족 선택 튜토리얼.
- 음성·애니메이션 연출.

## 7. 수용 기준

1. **엔진 재생 테스트**: 시나리오 상태에서 대본의 모든 단계(플레이어 행동 + 상대 수)를 실제 `RuleEngine`으로 적용했을 때 전부 합법이고, 끝나면 2라운드 행동 단계에 도달한다. 표 §4의 엔진 액션이 모두 한 번 이상 나온다. 끝난 상태에서 플레이어는 고급 타일 2장(연구판 1, Lost Fleet 1)과 회색 연방 토큰 2개를 갖고, 서로 다른 함선 3척을 탐사했으며, 종료 점수 미리보기 값이 `calculate_final_scoring_breakdown`과 같다.
2. **서버 테스트**: 대본과 다른 행동이나 다른 대상은 `TutorialStepMismatch`로 거절되고, 상태가 바뀌지 않는다. 단계 진행과 상대 수 적용이 스냅샷에 반영되고, 재접속 후에도 단계가 유지된다. 튜토리얼 방이 로비 목록에 나오지 않는다.
3. **프론트 테스트**: 단계별로 카드 문구와 강조 대상이 맞다. 대본 밖 행동을 누르면 안내가 뜨고 요청을 보내지 않는다.
4. **수동 확인**: 로컬 서버에서 처음부터 끝까지 브라우저로 진행해 26단계까지 막힘없이 끝난다.
5. 기존 일반 게임, dev 게임, AI 게임 동작과 테스트는 바뀌지 않는다.
6. **자원 상한 테스트**: 시작 상태와 대본의 모든 단계 직후 상태에서, 모든 좌석이 광석 ≤ 15, 지식 ≤ 15, 크레딧 ≤ 30이다.
7. DB가 필요한 서버 통합 테스트는 기존 관례대로 `#[ignore = "requires DATABASE_URL"]`를 붙인다.
