# 종족별 수동 테스트 체크리스트

기준: 2026-09-10, 현재 프로젝트의 **4인 + Lost Fleet** 규칙.
기대 결과의 근거는 [종족 능력 감사 보고서](faction-ability-audit-2026-09-10.md).
**규칙 검사는 제가 자동으로 진행합니다.** [자동 검증 결과](faction-test-results-2026-09-10.md)를 먼저 보세요.
`[x]`는 아래 명시된 엔진/컴포넌트 테스트로 기대 결과를 확인한 항목입니다. 실제 브라우저에서 사용자가 직접 확인했다는 뜻은 아닙니다.
`[ ]`는 전체 문장의 검증이 아직 끝나지 않았다는 뜻이며, 사용자에게 전부 맡긴 항목이 아닙니다.

## 사용 방법

1. 테스트할 종족 하나를 선택한다. 네 명 수동 조종으로 다른 플레이어의 패스·인접 건설도 직접 진행한다.
2. 아래 공통 항목과 해당 종족 항목을 확인한다. 한 번에 전부 할 필요는 없다.
3. 직접 테스트한 결과는 항목 ID와 함께 기록한다. 자동 검사와 다르면 체크 표시와 무관하게 버그로 알려준다. 조건을 만들지 못했으면 **미실시**로 남긴다.
4. 능력 자체와 로그를 따로 확인한다. 실제 자원은 맞는데 로그만 틀릴 수도 있다.

**주의 — 테스트 자원 보충을 누른 방에서는 수입·정확한 자원 증가량을 판정하지 마세요.**
보충은 광석/크레딧/지식/QIC를250, 파워 I/II/III를10씩 만든다. 광석·지식 정상 상한15, 크레딧30을 넘는 특수 상태이므로 보상 처리에서 숫자가 상한으로 내려갈 수 있다.
보충은 행동 접근·버튼 확인용으로만 쓰고, 시작 자원/비용 부족/보상량은 **보충하지 않은 정상 자원 게임**에서 확인한다. 현재 방을 삭제할 필요는 없다.

### 결과 기록 양식

```text
종족 / 항목 ID:

보충 사용 여부:
행동 및 대상:
행동 전 → 후: 광석 / 크레딧 / 지식 / QIC / 점수 / 파워(I, II, III, 가이아)
기대 결과:
실제 결과 / 로그 / 스크린샷:
성공 / 실패 / 미실시:
```

## 모든 종족 공통 — 종족마다 반복

- [ ] C1 시작: 배치 완료 직후 종족·건물·시작 연구가 맞는다. 시작 자원과 **1라운드 수입 후 자원**을 혼동하지 않는다.
- [ ] C2 건설: 이미지와 실제 건물 종류/색상이 일치하며, 비용은 안내와 동일하다. `최종 자원 = 이전 자원 - 비용 + 보상`으로 비교한다.
- [ ] C3 능력 조건: 의회 전/후, 사용 가능/이미 사용, 합법/불법 대상에서 버튼과 결과가 일치한다.
- [ ] C4 반복: 반복 보상은 두 번째에도 지급된다. 라운드당1회 행동은 두 번째 실행이 거절된다.
- [ ] C5 라운드: 네 명 모두 패스한다. 수입은 비워진 건물 칸·연구·기술 합계만큼 지급되고, 라운드당 행동만 다시 활성화된다. 게임당1회는 재활성화되지 않는다.
- [ ] C6 선택/취소: 대상·기술·연구 선택 중 다른 주요 행동은 막힌다. 취소하면 비용·보상·사용 표시가 남지 않는다.
- [ ] C7 되돌리기: 완료한 행동을 되돌리면 건물·자원·점수·기술·사용 표시가 함께 복원된다. 다시 실행해도 중복 지급되지 않는다.
- [ ] C8 저장: 행동 후 새로고침해 같은 방·종족·자원·사용 상태가 유지된다. 가능하면 탭을 닫고 같은 브라우저/주소의 이어하기도 확인한다.
- [ ] C9 점수: 해당 라운드 목표가 있을 때 기본 행동 점수와 종족/기술 보너스를 구분해 합산한다. 점수 숫자와 로그가 일치한다.

## 1. 테란 / Terrans
- [ ] TER1 시작 연구: 가이아1.
- [ ] TER2 의회 없이 가이아 단계를 마치면 가이아 파워가 I가 아니라 **II**로 돌아온다.
- [ ] TER3 의회 후 가이아 파워4→QIC1, 3→광석1, 4→지식1, 1→크레딧1을 각각 확인한다. 가이아 단계 완료 후 교환 분량을 포함한 토큰이 II로 돌아오며, 교환 때문에 토큰이 소멸하지 않는다.
- [ ] TER4 남은 파워 내에서 여러 번 교환 가능하며 부족하면 거절된다. 완료하면 나머지도 II로 돌아온다.

## 2. 란티다 / Lantids
- [ ] LAN1 상대 식민지에 공생 광산을 놓을 수 있고 테라포밍 비용은 없다. 광산 자체 비용은 별도다.
- [ ] LAN2 공생 광산은 업그레이드할 수 없다.
- [x] LAN3 의회 전 공생 광산은 추가 지식 없음. 의회 후 첫 번째·두 번째 공생 광산마다 지식2.
- [ ] LAN4 공생 광산은 행성 종류 수·가이아 식민지 수에 추가되지 않는다. 일반 단독 광산과 비교한다.
- [ ] LAN5 다음 수입에서 기본 파워 토큰 I에1 추가를 확인한다.

## 3. 제노스 / Xenos
- [ ] XEN1 광산3개 배치. 세 번째는 다른 종족의 통상 광산 배치 뒤에 놓는다. 시작 인공지능1.
- [ ] XEN2 의회 없이 건물 파워6 연방은 거절, 7은 다른 조건 충족 시 가능.
- [ ] XEN3 의회 후 건물 파워6 연방이 가능하다.
- [ ] XEN4 광석1→III 토큰1 자유행동을 두 번 해 광석-2/III+2, 턴 유지 확인.
- [ ] XEN5 의회 수입에서 일반 의회 토큰 수입 대신 QIC1.

## 4. 글린 / Gleens
- [ ] GLE1 시작 항법1. 정보 아카데미 전 QIC 보상이 광석으로 바뀐다. 건설 후에는 QIC로 받는다.
- [ ] GLE2 가이아 광산의 가이아 추가 비용은 QIC 대신 광석1. 첫 번째·두 번째 가이아 광산마다 종족 점수+2.
- [ ] GLE3 의회 건설 즉시 전용 연방 토큰과 인쇄 보상을1회 받는다. 연방 형성 라운드 목표가 있으면 해당 점수도 확인한다.
- [ ] GLE4 탐사판 항속+2 행동으로 광산/가이아 프로젝트/함선 탐사 중 하나를 실행한다. 같은 라운드 다른 선택지는 다시 사용할 수 없다.
- [ ] GLE5 다음 라운드 항속 행동은 다시 사용 가능하고 의회 전용 연방은 다시 받지 않는다.

## 5. 타클론 / Taklons
- [ ] TAK1 브레인스톤은 충전할 때 토큰1개처럼 I→II→III 이동한다.
- [ ] TAK2 III 브레인스톤 소비는 파워3으로 계산되고 I로 돌아간다. 파워3 소비에서 일반 토큰3개가 추가로 빠지지 않는다.
- [ ] TAK3 의회 후 상대 인접 건설의 충전 선택에서 토큰1 추가를 충전 전/후로 각각 시험한다. 선택한 순서대로 결과가 달라진다.
- [ ] TAK4 함선 탐사 시 브레인스톤이 가이아로 이동한다. 정상 가이아 반환도 확인한다.

## 6. 앰바스 / Ambas
- [ ] AMB1 시작 항법1. 의회 전 위치 교환 불가.
- [ ] AMB2 의회 후 자기 광산과 의회 위치가 교환되고 건물 개수는 그대로다.
- [ ] AMB3 교환으로 건설/업그레이드 점수나 상대 충전이 발생하지 않는다.
- [ ] AMB4 같은 라운드 재사용 불가, 다음 라운드 가능. 상대 광산은 대상 불가.

## 7. 하드쉬 할라 / HadschHallas

- [x] HAD2 의회 후 크레딧4→QIC1, 3→광석1, 4→지식1 각각 비용/보상 확인.
- [x] HAD3 같은 교환을 두 번 해도 정상 지급되고 턴을 넘기지 않는다.
- [x] HAD4 크레딧이 비용보다1 적을 때 거절되고 다른 자원이 변하지 않는다.

## 8. 하이브 / Ivits
- [ ] IVI1 광산 대신 의회1개를 마지막에 배치. 시작 파워 I2/II2를 수입 전 기준으로 확인.
- [ ] IVI2 첫 연방 파워7. 다음 확장은 기존 연방과 연결해야 하며 별도 연방은 불가.
- [x] IVI3 실제 연방 토큰1개면 두 번째 총파워14. 뒤집은 토큰도 개수에 포함된다.
- [x] IVI4 실제 연방1개+테라포밍5 보너스1개여도 두 번째 총파워14. 보너스 토큰/효과 자체는 사라지지 않는다.
- [ ] IVI5 확장 위성1개에 QIC1을 쓰며 일반 파워 토큰을 버리지 않는다.
- [ ] IVI6 빈 우주 칸에 우주정거장 배치: 연방 파워1·항속 출발점으로 사용. 행성/건물 수·상대 충전에는 포함되지 않는다. 같은 라운드 두 번째 배치 불가.

## 9. 지오덴 / Geodens
- [ ] GEO1 시작 테라포밍1. 의회 전에 점유한 행성 종류를 적어둔다.
- [ ] GEO2 의회 후 새로운 종류 첫 광산에 지식3.
- [ ] GEO3 같은 종류 두 번째 광산 및 의회 전에 이미 점유한 종류에는 추가 지식 없음.
- [ ] GEO4 또 다른 새 종류에는 지식3을 다시 받는다. 검은 행성도 새 종류라면 대상이다.

## 10. 발타크 / BalTaks
- [ ] BAL1 시작 가이아1. 의회 전 항법 상승은 지식/무료 연구 모두 불가.
- [ ] BAL2 가이아포머1개를 가이아 구역으로 옮겨 QIC1. 사용 가능한 포머 수는1 줄고, 남은 포머로 반복 가능.
- [ ] BAL3 다음 가이아 단계에서 해당 포머가 돌아온다. 의회 건설 후에는 항법 상승 가능.
- [ ] BAL4 정보 아카데미 행동은 QIC1 대신 크레딧4, 라운드당1회.
- [ ] BAL5 함선 탐사 점수 비용은 통상5가 아니라7. 별도 점수 보상이 있으면 구분한다.

## 11. 파이락 / Firaks
- [ ] FIR1 기본 지식 수입2 + 배치된 연구소당 지식1.
- [ ] FIR2 의회 전 강등 행동 불가. 의회 후 연구소→교역소와 무료 연구1이 한 행동으로 처리된다.
- [ ] FIR3 강등으로 발생하는 교역소 관련 보상·상대 충전을 확인한다. 강등 비용으로 통상 업그레이드 비용을 내지 않는다.
- [ ] FIR4 그 교역소를 다시 연구소로 올리면 정상 비용을 내고 기술을 새로 받는다.
- [ ] FIR5 강등 행동은 같은 라운드 재사용 불가, 다음 라운드 가능.

## 12. 매드 안드로이드 / Bescods
- [ ] BES1 교역소→아카데미, 연구소→의회 경로. 건물 보드 이미지/배치도 이를 반영한다.
- [ ] BES2 교역소 수입 지식1씩, 연구소 수입은 칸 순서대로 크레딧3/4/5. 시작 지식3은 첫 수입과 구분한다.
- [ ] BES3 의회 없이도 최저 연구 무료 상승 가능. 최저가 여러 개면 그중 하나를 직접 선택할 수 있다.
- [ ] BES4 최저가 아닌 트랙은 선택 불가. 5단계 진입에는 연방 뒤집기·다른 플레이어 점유 제한이 그대로 적용된다.
- [ ] BES5 의회 후 회색 행성 건물의 연방 파워+1. 다른 색 건물은 그대로다.
- [ ] BES6 무료 연구는 라운드당1회. 다음 라운드 다시 사용 가능.

## 13. 네뷸라 / Nevlas
- [ ] NEV1 시작 과학1. 연구소 수입은 각 파워 충전2.
- [x] NEV2 III 토큰1→가이아 이동+지식1을 두 번 실행: III-2/가이아+2/I 변화0, 총토큰 보존, 턴 유지.
- [x] NEV3 의회 후에도 NEV2는 토큰1당 지식1 그대로다.
- [x] NEV4 의회 전 파워4→QIC1에 토큰4, 의회 후 토큰2. 의회 후 파워3→광석1에는 토큰2.
- [ ] NEV5 의회 후 함선 비용: Twilight 연구소2토큰, Rebellion 교역소2, TF Mars 가이아1, Eclipse 연구2. 광석/지식 추가 비용은 그대로다.
- [ ] NEV6 가이아 프로젝트·위성·탐사의 **토큰 이동/폐기**에는 두 배 소비 효율을 적용하지 않는다. 함선 탐사 때 추가 토큰1 폐기도 확인한다.

## 14. 이타르 / Itars
- [ ] ITA1 II 토큰2 연소: 하나는 III로, 버리는 하나는 가이아로 이동한다. 두 번 실행 시 각각2개씩 이동.
- [ ] ITA2 의회 전 가이아 기술 획득 불가. 의회 후 가이아 단계에서 토큰4 폐기→일반 기술1과 해당 연구 처리.
- [x] ITA3 연구4 이상·초록 연방·덮을 일반 기술을 준비한다. 가이아 토큰4로 고급기술을 받고 일반 기술을 덮으며 연방1개를 뒤집는다.
- [ ] ITA4 고급기술이 놓인 트랙과 다른 트랙을 상승시킬 수 있다. 선택한 트랙도5로 올리려면 초록 연방이 추가로 필요하다.
- [ ] ITA5 가이아 토큰8이면 일반/고급을 합쳐 기술2개까지 반복 획득. 토큰3 이하로는 추가 획득 불가. 완료 전 다른 플레이어 행동으로 넘어가지 않는다.
- [x] ITA6 일반 기술을 받을 수 없고 조건에 맞는 고급기술만 남아도 가이아 기술 선택이 열린다.
- [ ] ITA7 과학 아카데미 수입 지식3. 함선 탐사는 추가 토큰1 폐기.

## 15. 팅커로이드 / Tinkeroids
- [ ] TIN1 소행성 의회1개로 시작하고 과학1. 의회 배치는 두 번째 초기 배치 단계 시작 시점.
- [ ] TIN2 배정된 비싼3색은 테라포밍3단계, 나머지 일반 색은1단계. 가이아 추가 비용 QIC2.
- [ ] TIN3 1–3라운드 타일: 무료 테라포밍1단계+광산 / QIC1 / 파워 충전4를 각 타일 선택 시 확인한다. 광산은 별도 정상 광산 비용을 확인한다.
- [ ] TIN4 4–6라운드 타일: QIC2 / 무료 테라포밍3단계+광산 / 지식3을 각 타일 선택 시 확인한다.
- [ ] TIN5 선택한 타일 행동은 라운드당1회. 사용하지 않았어도 라운드 종료 후 그 타일은 제거되며 다음 라운드 다른 타일을 선택한다.

## 16. 모웨이드 / Moweyds
- [ ] MOW1 원시행성 광산1개·가이아1. TF Mars 시작 셔틀1개, 잔여 셔틀2개. 시작 배치에서 탐사 점수 비용/슬롯 충전은 발생하지 않는다.
- [ ] MOW2 배정된 비싼3색은 테라포밍3단계, 나머지 일반 색은1단계. 배정된 색은 공용 남은 색 표시에서 빠진다.
- [ ] MOW3 의회 전 파워링 불가. 의회 후 자기 건물이 있는 행성에 설치 가능하고 건물 파워+2.
- [ ] MOW4 같은 행성 중복 설치·상대 건물 설치 불가. 라운드당1개, 전체 최대6개.
- [ ] MOW5 파워링이 있는 건물을 업그레이드/새로고침해도 링 효과가 유지된다.

## 17. 스페이스 자이언트 / SpaceGiants
- [ ] SPG1 원시행성 광산1개·항법1. 일반 행성 테라포밍2단계, 가이아 추가 비용 QIC2.
- [x] SPG2 의회 건설을 선택하면 즉시 기술 선택으로 연결된다. 건설과 기술 획득은 한 행동이며 턴을 두 번 쓰지 않는다.
- [x] SPG3 조건이 맞으면 의회 보상으로 고급기술도 선택 가능. 일반 덮기·연방 뒤집기·연구 상승은 정상 기술 규칙을 따른다.
- [ ] SPG4 의회 기술은 게임당1회. 다음 라운드/새로고침 후 다시 받을 수 없다.
- [ ] SPG5 탐사판 무료 테라포밍2단계+광산은 라운드당1회. 의회 기술 획득과 별개의 행동이다. 의회 수입 충전6도 확인한다.

## 18. 다카니안 / Darkanians
- [ ] DAR1 소행성 광산1개·항법1/경제1. 일반 행성 테라포밍1단계, 가이아 추가 비용 QIC2.
- [x] DAR2 의회 전 새 섹터 광산에는 종족 크레딧2/지식1 보상 없음.
- [x] DAR3 의회 후 아직 점유하지 않은 일반 우주 섹터 첫 광산에 크레딧2+지식1. 다른 새 섹터에서도 다시 받는다.
- [x] DAR4 깊은 우주 섹터의 첫 광산도 같은 보상. 인터스페이스에는 지급하지 않는다.
- [x] DAR5 같은 섹터 추가 광산·의회 전에 이미 점유한 섹터에는 보상 없음. 검은 행성 점유도 기존 점유로 센다.
- [x] DAR6 한 번 보상을 받은 뒤 새로고침하고 다른 새 섹터를 개척해도 정상 지급된다.
