# 가이아 프로젝트 온라인 — 사용자 스토리

**구성 방식**: Hybrid (User Journey 큰 틀 + Feature 세부)
**수용 기준 형식**: Given-When-Then (Gherkin)
**세분화**: 중간 (주요 게임 단계 기준)

---

## Epic 1: 게임 셋업 (Game Setup)

---

### US-01: 게임 룸 생성

**As a** 방장으로서,  
**I want to** 새 게임 룸을 생성하고 룸 코드를 받고 싶다,  
**So that** 친구들이 해당 코드로 참가할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 방장이 메인 화면에 있을 때
When 닉네임을 입력하고 "새 게임 만들기"를 클릭하면
Then 고유한 4~6자리 룸 코드가 생성된다
And 랜더마이저가 자동 실행되어 게임 셋업이 생성된다 (Lost Fleet + Center Balance 고정)
And 방장은 대기실 화면으로 이동한다
And 룸 코드를 클립보드에 복사하는 버튼이 제공된다

Given 방장이 대기실에 있을 때
When 3명의 플레이어가 추가로 참가하면
Then "게임 시작" 버튼이 활성화된다

Given 4명 미만인 상태에서
When 방장이 "게임 시작"을 클릭하려 하면
Then "4명이 모두 참가해야 시작할 수 있습니다" 안내가 표시된다
```

---

### US-02: 게임 룸 참가

**As a** 참여 플레이어로서,  
**I want to** 룸 코드와 닉네임으로 게임에 참가하고 싶다,  
**So that** 별도 계정 없이 바로 게임을 시작할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 플레이어가 메인 화면에 있을 때
When 닉네임과 룸 코드를 입력하고 "참가"를 클릭하면
Then 대기실 화면으로 이동한다
And 현재 참가한 플레이어 목록이 표시된다

Given 이미 4명이 참가한 룸에
When 5번째 플레이어가 참가를 시도하면
Then "정원이 찼습니다" 오류 메시지가 표시된다

Given 존재하지 않는 룸 코드를 입력했을 때
When "참가"를 클릭하면
Then "유효하지 않은 룸 코드입니다" 오류 메시지가 표시된다

Given 플레이어가 연결이 끊겼다가 재접속했을 때
When 같은 룸 코드와 닉네임으로 다시 참가하면
Then 기존 자리로 복귀한다
```

---

### US-03: 랜더마이저 셋업 확인 및 재생성

**As a** 방장으로서,  
**I want to** 생성된 게임 셋업을 확인하고 마음에 들지 않으면 재생성하고 싶다,  
**So that** 원하는 게임 환경에서 시작할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 방장이 대기실에 있을 때
When 랜더마이저 결과 패널을 열면
Then 다음이 표시된다:
  - 배정된 팩션 쌍 4개 (각 플레이어 슬롯에 1쌍)
  - 표준 테크 타일 9개 배치
  - 어드밴스드 테크 타일 7개 (리서치 트랙별)
  - 라운드 득점 타일 6개 (라운드 순서대로)
  - 라운드 부스터 7개
  - 최종 득점 타일 2개
  - 맵 프리뷰 (섹터 배치)

Given 방장이 랜더마이저 결과를 확인했을 때
When "재생성" 버튼을 클릭하면
Then 새 시드로 모든 셋업이 재생성된다
And 참가한 플레이어 화면에도 업데이트가 반영된다

Given 방장이 특정 시드로 고정하고 싶을 때
When 시드 값을 직접 입력하고 "적용"하면
Then 해당 시드 기반의 동일한 셋업이 재현된다

Given 셋업이 확정되었을 때
When 방장이 셋업 공유 버튼을 클릭하면
Then seed와 rotation이 포함된 공유 코드/링크가 생성된다
```

---

### US-04: 팩션 선택 모드 결정

**As a** 방장으로서,  
**I want to** 게임에 맞는 팩션 선택 방식을 설정하고 싶다,  
**So that** 플레이어 숙련도에 맞는 공정한 팩션 배정이 이루어진다.

**Acceptance Criteria:**

```gherkin
Given 방장이 대기실에서 게임 설정을 할 때
When 팩션 선택 모드를 선택하면
Then 다음 2가지 모드 중 하나를 선택할 수 있다:
  - "자유 선택" (기본 / 초보 권장): 각 플레이어가 원하는 팩션 직접 선택, LLM 조언 요청 가능
  - "비딩 경매" (숙련 권장): VP 비딩을 통해 팩션과 턴 순서 경매, LLM 조언 요청 가능

Given 방장이 모드를 선택하면
When 참가한 모든 플레이어가 대기실을 확인하면
Then 선택된 팩션 모드가 표시된다
And 모드 설명이 안내 텍스트로 제공된다
```

---

### US-05: 자유 팩션 선택 (LLM 조언 선택적 지원)

**As a** 참여 플레이어로서,  
**I want to** 랜더마이저가 배정한 팩션 쌍 중 원하는 팩션을 직접 선택하되, 필요하면 LLM 조언을 받고 싶다,  
**So that** 내 판단으로 팩션을 고르거나 AI의 도움을 받아 더 나은 선택을 할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 팩션 선택 모드가 "자유 선택"이고 팩션 선택 단계가 시작되었을 때
When 내 차례가 되면
Then 배정된 쌍에서 2개의 팩션 이미지와 설명이 표시된다
And 각 팩션의 홈 행성 타입, 특수 능력 요약이 표시된다
And "AI에게 추천 받기" 버튼이 제공된다

Given 팩션 선택 화면에서 "AI에게 추천 받기"를 클릭했을 때
When LLM이 분석을 완료하면
Then 2개의 팩션 중 추천 팩션이 하이라이트되고 추천 이유가 표시된다
And 플레이어는 추천을 따르거나 직접 다른 팩션을 선택할 수 있다 (강제 아님)

Given 팩션 선택 화면이 표시될 때
When 플레이어가 팩션 중 하나를 선택하면
Then 해당 팩션이 확정되고 게임 보드에 표시된다
And 선택하지 않은 팩션은 게임에서 제외된다

Given 모든 4명의 팩션이 선택된 후
When 방장이 확인하면
Then 팩션 선택 단계가 완료되고 게임 시작 준비가 된다
```

---

### US-07: 비딩 경매로 팩션 선택

**As a** 플레이어로서,  
**I want to** 비딩 경매를 통해 원하는 팩션과 턴 순서를 획득하고 싶다,  
**So that** 전략적으로 팩션 우선순위를 결정할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 팩션 선택 모드가 "비딩 경매"이고 경매가 시작되었을 때
When 첫 번째 라운드가 시작되면
Then 4명의 팩션 쌍 목록이 모두 공개된다
And 시계방향으로 첫 번째 플레이어부터 입찰 가능

Given 플레이어의 입찰 차례일 때
When 현재 최고 입찰가가 N VP일 때
Then 해당 플레이어는 N+1 이상의 VP를 입찰하거나 패스할 수 있다

Given 플레이어가 패스했을 때
When 이후 라운드에서도 해당 경매에 참여할 수 없으며
Then 다음 플레이어로 진행된다

Given 한 명을 제외한 모든 플레이어가 패스했을 때
When 마지막 입찰자가 낙찰되면
Then 낙찰자는 4개의 팩션 쌍 중 원하는 팩션 1개를 선택한다
And 원하는 턴 순서 1개를 선택한다
And 낙찰 VP는 게임 종료 시 최종 점수에서 차감됨이 표시된다

Given 1명의 팩션이 확정된 후
When 다음 경매 라운드가 시작되면
Then 남은 3명의 플레이어가 남은 3개의 팩션 쌍으로 재경매한다
And 이전 라운드와 같은 방식으로 진행된다

Given 3번의 경매 라운드 후
When 3명이 팩션을 확정했을 때
Then 마지막 남은 플레이어는 자동으로 남은 팩션 쌍을 배정받는다
And 남은 턴 순서를 배정받는다
And 마지막 플레이어의 VP 차감은 없다

Given 모든 경매가 완료된 후
When 플레이어들이 확인하면
Then 팩션, 턴 순서, 낙찰 VP 차감 요약이 표시된다
```

## Epic 2: 게임 진행 (In-Game Play)

---

### US-08: 게임 보드 확인

**As a** 플레이어로서,  
**I want to** 현재 게임 보드와 모든 플레이어 상태를 한눈에 확인하고 싶다,  
**So that** 전략적 결정을 내릴 수 있다.

**Acceptance Criteria:**

```gherkin
Given 게임이 진행 중일 때
When 게임 화면을 열면
Then 헥사곤 게임 보드가 표시된다 (10개 섹터 + Lost Fleet 딥 스페이스)
And 각 행성의 색상(유형)과 구조물이 표시된다
And 4명의 플레이어 대시보드가 표시된다:
  - 팩션명과 색상
  - 자원 현황 (광석, 지식, 크레딧, QIC)
  - 파워 사이클 현황 (Braintrust 1/2/3, Gaia Area)
  - 리서치 트랙 레벨 (6개 트랙)
  - 현재 승리 포인트

Given 게임 보드가 표시될 때
When 행성을 클릭하면
Then 해당 행성의 소유자, 구조물 종류, 건설 가능 여부가 표시된다

Given 게임 보드가 표시될 때
When 리서치 트랙을 클릭하면
Then 해당 트랙의 레벨별 효과와 테크 타일이 표시된다
```

---

### US-09: 내 턴에 액션 수행

**As a** 플레이어로서,  
**I want to** 내 턴에 유효한 게임 액션을 수행하고 싶다,  
**So that** 전략에 따라 제국을 확장할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 현재 내 턴일 때
When 게임 화면을 확인하면
Then 수행 가능한 액션 목록이 활성화된다:
  - 마인 건설 (자원 충분 시)
  - 구조물 업그레이드 (가능한 구조물 존재 시)
  - 테라포밍 + 건설 (테라포밍 자원 충분 시)
  - 파워 액션 (사용 가능한 파워 액션 슬롯)
  - 특수 액션 (팩션/테크 타일 특수 능력)
  - 가이아 프로젝트 시작
  - 패스

Given 내가 "마인 건설"을 선택했을 때
When 건설 가능한 행성들이 하이라이트되면
Then 자원이 부족한 행성은 비활성화(회색)로 표시된다
And 유효한 행성을 클릭하면 자원이 차감되고 마인이 배치된다

Given 내가 액션을 완료했을 때
When 서버에 액션이 전송되면
Then 모든 플레이어의 화면에 결과가 실시간 반영된다
And 다음 플레이어의 턴으로 넘어간다

Given 내가 잘못된 액션을 시도했을 때
When 서버에서 유효성 검사에 실패하면
Then "유효하지 않은 액션" 메시지가 표시된다
And 이전 상태로 롤백된다
```

---

### US-10: 라운드 패스

**As a** 플레이어로서,  
**I want to** 원할 때 패스하여 라운드 부스터를 선택하고 싶다,  
**So that** 자원 상황에 맞춰 전략적으로 라운드를 마무리할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 내 턴이고 패스를 선택했을 때
When 사용 가능한 라운드 부스터 목록이 표시되면
Then 현재 내가 보유한 부스터는 반납 표시된다
And 사용 가능한 부스터 중 하나를 선택한다

Given 라운드 부스터를 선택했을 때
When 패스가 확정되면
Then 이번 라운드에서 내 차례가 종료된다
And 새 부스터 효과가 즉시 적용된다
And 라운드 득점이 계산되어 표시된다

Given 모든 플레이어가 패스했을 때
When 라운드가 종료되면
Then 다음 라운드가 시작되거나 (6라운드 후) 최종 득점 단계로 진입한다
```

---

### US-11: 다른 플레이어 턴 대기 중 관전

**As a** 플레이어로서,  
**I want to** 내 턴이 아닐 때도 게임 진행 상황을 실시간으로 확인하고 싶다,  
**So that** 다른 플레이어의 전략을 파악하고 내 다음 액션을 준비할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 다른 플레이어의 턴일 때
When 게임 화면을 보면
Then 현재 액션 중인 플레이어가 하이라이트된다
And 해당 플레이어의 액션이 보드에 실시간으로 반영된다
And 내 액션 버튼은 비활성화된다

Given 다른 플레이어의 턴일 때
When 대기 중에 AI 코칭을 요청하면
Then 현재 게임 상태 기반으로 AI 코칭 패널이 열린다 (게임 진행 차단 없음)

Given 다른 플레이어의 턴일 때
When 게임 로그 패널을 열면
Then 직전까지의 모든 액션 이력이 시간순으로 표시된다
```

---

### US-12: 게임 로그 확인

**As a** 플레이어로서,  
**I want to** 이번 게임에서 발생한 모든 액션의 이력을 확인하고 싶다,  
**So that** 어떤 일이 있었는지 파악하고 전략을 재검토할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 게임이 진행 중일 때
When 게임 로그 패널을 열면
Then 최근 액션부터 내림차순으로 로그가 표시된다
And 각 로그 항목에는 플레이어명, 라운드, 액션 종류, 결과가 표시된다

Given 게임 로그에서 특정 라운드를 선택하면
When 해당 라운드의 액션만 필터링되면
Then 해당 라운드의 전체 플레이 흐름이 표시된다
```

---

### US-13: 내 리소스 및 상태 확인

**As a** 플레이어로서,  
**I want to** 내 현재 자원, 파워, 리서치 트랙 상태를 언제든 확인하고 싶다,  
**So that** 다음 액션에 필요한 자원이 충분한지 판단할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 게임이 진행 중일 때
When 내 대시보드 패널을 열면
Then 다음이 표시된다:
  - 광석(Ore), 지식(Knowledge), 크레딧(Credit), QIC 수량
  - 파워 사이클: Braintrust 1/2/3 각각의 파워 토큰 수, Gaia Area 토큰 수
  - 6개 리서치 트랙 현재 레벨 (0~5)
  - 보유 중인 테크 타일 및 어드밴스드 테크 타일
  - 현재 구조물 현황 (남은 마인, 트레이딩 스테이션 등)
  - 연방 토큰 보유 현황
  - 현재 승리 포인트 합계

Given 리서치 트랙 레벨이 5가 될 때
When 자동 연방 토큰 획득이 발생하면
Then 즉시 대시보드에 반영되고 알림이 표시된다
```

---

### US-14: 라운드 득점 확인

**As a** 플레이어로서,  
**I want to** 각 라운드 종료 시 득점 내역을 확인하고 싶다,  
**So that** 라운드 타일 보너스 달성 여부와 내 점수 추이를 파악할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 라운드가 종료되었을 때
When 라운드 득점 화면이 표시되면
Then 각 플레이어의 라운드 타일 달성 여부와 획득 VP가 표시된다
And 전체 VP 순위가 업데이트된다

Given 라운드 득점 화면에서
When 특정 플레이어의 득점 항목을 클릭하면
Then 해당 득점의 상세 내역이 표시된다 (어떤 조건으로 몇 VP 획득)
```

## Epic 3: 게임 종료 (Game End)

---

### US-15: 최종 득점 계산 및 확인

**As a** 플레이어로서,  
**I want to** 게임 종료 시 전체 득점 내역을 카테고리별로 확인하고 싶다,  
**So that** 내가 어떤 전략이 효과적이었는지 파악할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 6라운드가 모두 종료되었을 때
When 최종 득점 화면이 표시되면
Then 다음 항목별 VP가 플레이어별로 표시된다:
  - 라운드별 보너스 VP 합계
  - 연방 토큰 VP
  - 리서치 트랙 VP (각 트랙별 최종 레벨 기반)
  - 최종 득점 타일 1 VP
  - 최종 득점 타일 2 VP
  - 구조물 VP
  - 자원 변환 VP
  - 비딩 경매 VP 차감 (비딩 모드인 경우)
  - **최종 합계 VP**
And VP 순위에 따라 1~4위가 표시된다

Given 동점인 경우
When 최종 득점이 동일하면
Then 타이브레이커 규칙 (자원 합계 등)이 적용되어 순위가 결정된다
```

---

### US-16: 게임 결과 화면

**As a** 플레이어로서,  
**I want to** 게임 종료 후 승자와 전체 결과를 확인하고 싶다,  
**So that** 게임을 마무리하고 다음 게임 여부를 결정할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 최종 득점이 완료된 후
When 결과 화면이 표시되면
Then 1위 플레이어가 승자로 강조 표시된다
And 전체 4명의 최종 순위와 VP가 표시된다

Given 결과 화면에서
When "같은 멤버로 새 게임" 버튼을 클릭하면
Then 새 랜더마이저 셋업과 함께 새 게임이 시작된다

Given 결과 화면에서
When "나가기"를 클릭하면
Then 메인 화면으로 돌아간다
And 해당 룸은 종료된다
```

## Epic 4: AI 코칭 (LLM Coaching — Phase 1)

---

### US-17: AI 코칭 요청

**As a** 플레이어로서,  
**I want to** 현재 게임 상황에서 AI 코치에게 조언을 요청하고 싶다,  
**So that** 최선의 다음 액션을 결정하는 데 도움을 받을 수 있다.

**Acceptance Criteria:**

```gherkin
Given 게임이 진행 중이고 (내 턴이거나 대기 중이거나)
When 코칭 패널 버튼을 클릭하면
Then AI 코칭 패널이 게임 화면 위에 오버레이로 열린다
And 게임 진행은 차단되지 않는다

Given 코칭 패널이 열렸을 때
When "현재 상황 분석 요청" 버튼을 클릭하면
Then 현재 게임 상태 (내 자원, 보드 상태, 라운드, 점수 차이 등)가 LLM에 전달된다
And 30초 이내에 분석 결과와 추천 액션이 텍스트로 표시된다

Given AI 코칭 응답이 표시된 후
When 플레이어가 응답을 읽으면
Then 추천된 액션을 따르거나 무시할 수 있다 (강제 아님)
```

---

### US-18: 규칙 질문

**As a** 플레이어로서,  
**I want to** 게임 중 헷갈리는 규칙을 AI에게 질문하고 싶다,  
**So that** 룰북을 별도로 찾아보지 않아도 빠르게 답을 얻을 수 있다.

**Acceptance Criteria:**

```gherkin
Given 코칭 패널이 열려 있을 때
When 자연어로 규칙 질문을 입력하면
  (예: "가이아 포머를 놓으면 그 라운드에 바로 가이아 행성이 되나요?")
Then RAG 시스템이 룰북에서 관련 규칙을 검색한다
And 30초 이내에 규칙 설명이 답변으로 표시된다
And 관련 룰북 섹션 참조가 표시된다

Given AI 답변이 표시된 후
When 추가 질문을 입력하면
Then 이전 대화 맥락을 유지하며 답변한다
```

---

### US-19: 현재 상황 기반 전략 조언

**As a** 플레이어로서,  
**I want to** 내 팩션 특성과 현재 보드 상황을 고려한 전략 조언을 받고 싶다,  
**So that** 내 팩션의 강점을 최대한 활용할 수 있다.

**Acceptance Criteria:**

```gherkin
Given 코칭 패널이 열려 있을 때
When "팩션 전략 조언 보기"를 클릭하면
Then 내 팩션 (예: Nevlas)의 특수 능력과 현재 게임 상황을 종합하여
And 이번 라운드에서 집중해야 할 전략 방향이 표시된다
And 우선순위 액션 Top 3가 추천된다

Given 전략 조언이 표시된 후
When "다른 플레이어 대비 내 위치"를 요청하면
Then 현재 VP 순위, 리서치 트랙 비교, 연방 형성 현황이 요약된다
And 부족한 부분에 대한 보완 전략이 제안된다
```
