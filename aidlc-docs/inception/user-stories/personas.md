# 가이아 프로젝트 온라인 — 사용자 페르소나

## Persona 1: 방장 (Host / 게임 마스터)

| 항목 | 내용 |
|---|---|
| **이름** | 방장 |
| **역할** | 게임 룸을 생성하고 설정을 결정하는 플레이어 |
| **특징** | 가이아 프로젝트 규칙에 익숙하며, 플레이 세션을 주도함 |
| **목표** | 친구들과 함께 쾌적한 게임 환경을 설정하고 공정한 게임을 진행 |
| **불만** | 설정이 복잡하거나 오래 걸리는 것, 기술적 오류로 게임이 중단되는 것 |
| **행동 패턴** | 게임 시작 전 랜더마이저 결과를 확인하고 재생성, 팩션 선택 방식 결정 |

**담당 여정:**
- 게임 룸 생성 및 코드 공유
- 팩션 선택 모드 결정 (AI 추천 / 자유 선택 / 비딩)
- 랜더마이저 셋업 확인 및 재생성
- 게임 시작 승인

## Persona 2: 참여 플레이어 (Participating Player)

| 항목 | 내용 |
|---|---|
| **이름** | 참여 플레이어 |
| **역할** | 룸 코드로 참가하는 게임 플레이어 |
| **특징** | 초보부터 숙련까지 다양한 수준; 닉네임으로 입장 (계정 불필요) |
| **목표** | 자신의 팩션으로 전략적으로 게임을 플레이하고 승리 |
| **불만** | 유효하지 않은 액션 시도 시 혼란, 다른 플레이어 턴을 오래 기다리는 것 |
| **행동 패턴** | 자기 턴에 액션 수행, 대기 중 AI 코칭 조회 및 게임 로그 확인 |

**담당 여정:**
- 닉네임 입력 후 룸 코드로 참가
- 팩션 선택 (모드에 따라 다름)
- 게임 액션 수행 (자기 턴)
- 대기 중 AI 코칭 조회
- 최종 득점 확인
