## 삭제후보에서 제외하는 실제 규칙
기존 인벤토리의 혼합 행은 아래 규칙 부분과 임의 계수를 분리해서 읽는다. 기존 교사 코드는 수정하지 않았다.
| 보존할 규칙 | 근거 | 여전히 임의인 부분 |
|---|---|---|
| 연구 3·4·5단계당 누적 4 VP | gaia-engine/src/scoring.rs::research_track_vp | 단계 접근 할인·추가 +2 등은 별도 휴리스틱 |
| 최종 점수 타일 인쇄 순위 VP와 동점 공동분배·버림 | ScoringEngine::final_scoring_metric / calculate_final_scoring_breakdown | 현재 순위가 최종 순위라는 전망은 불확실 |
| 기술 타일 7의 즉시 7 VP 및 타일별 인쇄 보상·조건부 실제 발동 VP | engine.rs::apply_tech_tile_immediate_reward 및 tech_tile_event_vp_per_unit | 이미 받은 보상 재가산·가정한 발동 횟수는 제거/보정 대상 |
| 연방 토큰 종류별 인쇄 VP·자원 | engine.rs::apply_federation_token_direct_reward | 연방 준비 +8/+12, 대기/위성 별도 벌점은 규칙 아님 |
| 연구 단계별 항해 거리·테라포밍 광석·가이아 파워 비용·보상 | engine.rs::evaluation_data → 실제 엔진 상수/함수 및 research_tracks.toml | 연구로 생길 미실현 행성의 기대가치는 휴리스틱 |
| 실제 광산 건설 비용·가이아 진입 QIC·항해 연장 QIC·연구 지식 비용 | engine.rs::validate_build_impl / range_and_qic_cost / validate_research | 자원당 VP 환산가격은 휴리스틱 |
| 종료 시 광석+크레딧+지식 합계 3개당 1 VP | ScoringEngine::calculate_final_scoring_breakdown | QIC·파워에 직접 종료 VP를 주는 것은 해당 규칙 아님 |
