# A02 — 이번 라운드 투자와 패스 비교

## 승인 범위 — 2026-09-28

- 사용자는 `즉시 패스`와 `현재 라운드 건설·업그레이드 → 패스 → 다음 수입`의
  비교를 승인했다. 최대 2회 제한은 거절했고, 라운드 투자 횟수를 제한하거나
  강제하지 않으며 기존 시간 한도 안에서 탐색하도록 확정했다.
- 동결 A, 자원 가격, 수입·기술·연방 평가식, 엔진·보상·기존 시간 배분은 유지한다.
  소비 보너스, 패스 벌점/금지, 교역소 금지, 특정 좌표 강제는 추가하지 않는다.
- A02는 별도 파생 소스의 기본 OFF 실험이다. 이번 범위는 구현·저장 상태 기능 검증이며
  새 전판/A-B/학습/채택/배포가 아니다. 다른 작업의 최신 교사·기록을 변경하지 않는다.

## 구현 경계

- 첫 대상은 진단에서 확인한 테란·타클론의 정상 행동 단계에서 로컬 기준 수가 패스인 경우다.
  그 외와 OFF는 원래 A 검색을 호출한다. R1 오프닝의 기존 유지/전환 선택을 보존한다.
- 투자 후보는 실제 합법 `Build`/`Upgrade` 중 기존 보존 정책을 통과한 행동이다.
  매 투자 뒤 실제 상대/충전/강제 결정을 기존 A의 얕은 예측 정책으로 처리한다.
  자금조달 행동·특수 건설 종류 확대는 이번 실험에 포함하지 않는다.
- 각 투자 접두 경로에서 패스한 뒤 다음 라운드의 첫 ActionPhase(수입·가이아 단계 후),
  또는 실제 게임 종료까지 실행한 결과만 비교한다. 미완료 경로에 값을 만들지 않는다.
- 횟수 제한 없는 투자 트리를 기존 로컬 평가 순으로 탐색한다. 점수는 순서에만 사용하고,
  선택은 동일 종료 경계의 기존 leaf 평가로만 한다. 기존 192 native 전이 안전 상한은 유지한다.
- 기준 패스 완료 전에는 투자 경로를 선택하지 않는다. 시간 초과 시 마지막 완료 비교의 수,
  비교가 없으면 기존 로컬 수/부모의 기존 reserve 계약을 유지한다. 가상 미래 메모리는
  실제 정책에 복사하지 않고 다음 실제 차례에 다시 판단한다.

## 검증 기준

1. OFF/비대상은 원래 검색으로 위임; 평가식·동결 A 해시 불변.
2. 기준/대안 동일 경계, 실제 비용/상대 차례, 원본 상태 불변.
3. 3회 이상 투자 경로를 탐색 가능; 이익 없는 소비/교역소를 강제하지 않음.
4. timeout/전이 상한/합법 후속 부재는 unknown이며 미완료 값으로 선택하지 않음.
5. 저장 seed5140 step28에서 실제 timed worker 연결, 선택 근거·완료 범위·시간 기록.
6. 높은 크레딧/부족 광석에서 경로별 남은 자원·수입·다음 합법 행동을 함께 보고.
7. 대상 테스트 후 기존 Python/엔진/Clippy/불변식 게이트. 기존 실패는 분리 기록.

## 저장 상태 기능 검증 — v2

교정 엔진 ON, seed5140/step28, 테란 R1, 실제 worker의 기존 10초 배분에서 비교했다.
과거 기보의 행동 접두부를 native로 재생했으나 controller 메모리는 새로 시작한다.
따라서 과거 대국 정책 메모리를 완전히 재현한 시험이나 새 전판 대국이 아니다.

- OFF: 9.909초, 기존 `Pass(10)` 유지. ON: 9.910초, 첫 수 `Upgrade -4,6 TradingStation` 선택.
  후속 두 수는 **예측 경로**이며 실제 실행/완수되었다는 뜻이 아니다. 기존 BGG 선택기는
  `1RL+2M`에 맞는 같은 경로를 선택했다. 테란 이 좌표에 대한 하드코딩은 없다.
- ON에서 완료 경로17개(즉시 패스 포함)를 별도 native 재생으로 검증했다.
  최대 완료 투자3회, 게시 시점 미탐색39개이며 전체 최적성은 주장하지 않는다.
  합성 회귀에서는4회 투자도 탐색·선택된다. 어떤 횟수도 강제하지 않는다.
- 두 광산 뒤 교역소를 추가하면 **153.82→148.50으로 감소**한다. 소비 자체를 보상하지 않는다.
  반면 교역소 단독은 불리해도 연구소와 광산까지 잇는 전체 경로는 유리하게 평가됐다.
- 선택 경로의 R2 자원은 광석4/크레딧14/지식4/QIC0, 영구 수입은 광석3/크레딧6/지식3이다.
  즉시 패스는 자원11/17/2/1, 영구 수입3/2/1이다. 선택 경로의 R2 첫 차례는 상대이므로
  자기 다음 합법 행동 수는 **미관측(null)**으로 남겼다. 미래 수입 벡터는 원래 평가식 그대로다.

### 자원 불균형 — 해결 판정 불가

| 같은 seed의 저장 상태 | 시작 광석/크레딧/지식 | 완료 경로 수 | 선택·해석 |
|---|---|---:|---|
| step86 타클론 R3 | 3/15/7 | 0 | 로컬 패스 유지. 기준 경로부터 시간 안에 완료하지 못함 |
| step91 테란 R3 | 7/13/3 | 0 | 동일. 대안을 평가해 패스를 이겼다는 뜻 아님 |
| step106 타클론 R3 | 6/25/11 | 1 | 즉시 패스만 완료. 투자 경로 우열 미확인 |

세 경우 모두 약9.90초 안에 반환했다. 기준 패스를 완주한 뒤 투자 후보를 비교하는 방식은
중반의 비싼 상대 예측에서 여전히 진도가 나가지 못한다. **과잉 교역소 문제나 이른 패스가
해결됐다는 증거가 아니다.** 공통 경계/미완료 unknown 계약과 시간 한도를 지켜 원래 패스를
유지했다. 이를 숨기기 위해 시간 증가, 상대 생략, 미완료 점수 보간을 하지 않았다.

## 재현

`tools/build_a02_source.py --output gaia-rl/runs/<새 디렉터리>`를 Python으로 실행하면
동결 A를 검증한 뒤 별도 파생 소스를 만든다. 기존 디렉터리를 덮어쓰지 않는다.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 gaia-rl/tools/build_a02_source.py \
  --output gaia-rl/runs/a02-source-new
PYTHONDONTWRITEBYTECODE=1 GAIA_ENGINE_FIXES_2=1 GAIA_A02_ROUND_INVESTMENT=1 \
PYTHONPATH=gaia-rl/python:gaia-rl/runs/a02-source-new:gaia-rl/tools \
gaia-rl/.venv/bin/python gaia-rl/tools/probe_a02_round.py \
  gaia-rl/runs/cycle-007-baseline-noise/a/state-evaluation-ab-20260917-5140/decisions.jsonl.gz \
  --step 28 --output gaia-rl/runs/a02-probe-new.json
```

플래그를0으로 바꾸면 동일 파생 소스에서 기존 A 검색을 사용한다. 재실행의 시간 기반
완료 경로 수는 달라질 수 있다. 원시 v2 receipt는 `runs/a02-probes-20260928/`,
소스 파생 manifest는 `runs/a02-source-20260928-v2/A02_DERIVATION.json`에 있다.
