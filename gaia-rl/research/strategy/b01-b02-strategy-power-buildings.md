## B01 전반 전략

| id | 주장 | 코드 |
|---|---|---|
| B1-1 | 원칙 1: 모든 자원 사이 **균형**. 지식 높은 종족은 자원을, 자원 많은 종족은 지식을 달림. 광석:돈 이상 비율 1:1.8, 광석이 늘 부족(얻기 3.5배 어려움) | △ `materials` 오목 함수(5광석·10돈 이후 체감) |
| B1-2 | 원칙 2: **수입 대신 점수**. 1–3R은 점수를 깎아 자원을 얻고, **4–6R은 자원보다 눈앞의 점수**. 연방 목표를 낮게 잡고 남은 자원은 라운드 보너스·부스터·정보 액션으로 점수화 | △ 남은 라운드 비례 수입 가치(LF1-04 라운드 환율과 같은 방향) |
| B1-3 | 점수 가이드(평균 177점): 연방 21(3연방 기준, 4연방은 큰 건물 4티어 필수), 연구 트랙 28(5+4+4단계), 연방 토큰 뒤집기(고급 기술·5단계) 36, 정보 액션 14(정보 큐브당 3–4점, 3연방 각이면 4R부터 매 턴), 라운드 부스터 15(4–6R 5–8점), 라운드 보너스 25, 미션 24 | ✗ 점수 원천별 목표 없음 |
| B1-4 | 패스당 점수 고급 기술 20점+, 즉발 점수형 12–16점. 가이아 광산당 3점 기술을 1–2번째로 집으면 15–24점 | ✗ |
| B1-5 | 라운드 부스터: 4–6R은 점수 부스터. 4/5R에 일찍 패스해 좋은 부스터를 가져가는 것도. 큰 건물당 4점 부스터는 거의 무조건 좋음 | ✗ |
| B1-6 | 라운드 보너스 흐름을 보고 게임을 짬. 예: 1R 큰 건물 보너스면 의회·아카데미 오프닝, 광산당 점수 다음 라운드에 대비해 광산 배치, 가이아 보너스 라운드를 위해 **포머를 일부러 회수 안 하고 남김** | ✗ |
| B1-7 | 미션: 하나 포기하고 하나만 달리는 건 보통 나쁨, 둘 다 반쯤 잡도록. 건물 수·연방 건물 수 미션이면 큰 건물보다 저티어를 넓게 | ✗ |
| B1-8 | 트랙 sweet spot: **테라포밍 0 또는 3단계 이상(4–5)**, 1테라에 3광석 내지 말 것(2광석도 웬만하면). **항해 2단계(필요하고 충분)**. 인공지능 없음(4–5R부터 정보 액션용). **가이아 1 또는 5**. **경제 2 또는 4**(3은 +1충전+1돈뿐). **과학은 지식 수입이 짝수가 되는 단계**, 초반부터 올려 고급 기술·5단계를 노리거나 아예 0 | ✗ 트랙 계수(research_options 근접도)만 |
| B1-9 | 항해 3단계와 인공지능 1단계 고민 시, 당장 3충전 급하지 않으면 인공지능 | ✗ |
| B1-10 | 행성 확보 시너지: 테라포밍+항해 / 가이아+항해. 경제와 가이아를 같이 올리면 파워가 넘쳐 아쉬움. 테라포밍·가이아 동시는 여력 없음(아이타·테란·발타크 예외) | ✗ |
| B1-11 | 테라포밍 5단계가 가장 효율 좋은 5단계(경쟁 셈). 4R 이후 광석 충분할 때 달림 | ✗ |

## B02 파워·자원·건물

| id | 주장 | 코드 |
|---|---|---|
| B2-1 | 파워 = **충전량(I=0, II=1, III=2충전) + 절대량(토큰 수)**. 토큰을 터뜨려 부스팅하면 충전량은 유지되고 절대량만 1 감소 = 그 토큰이 처음부터 없던 것과 같음 | △ `power_value`가 그릇별 값(0.2/0.6/1.4) |
| B2-2 | **토큰 적정량 ≈ 5**(3–4파워 액션 기준). 포머 운용 시 10–11개(가이아 1단계) 또는 8–9개(3단계). 적정량 이상이면 **토큰 가치 0**, 포머·연방 예정으로 부족할 때만 가치(≈4충전) | ✗ 토큰 가치 없음(LF01은 확장판 3.2충전) |
| B2-3 | 리치: ABC. 5R까지 2충전은 무조건, 3충전도 3–4R까지 무조건, 4충전 이상은 중요한 타이밍 아니면 받지 않음 | ? 리치 판단 위치 확인 필요(LF04: 함대 입장 점수와 함께) |
| B2-4 | 리치를 일부러 안 주거나(질질 끌기) 타클론·네블라처럼 파워를 주기 싫은 종족을 피해 배치 | ✗ |
| B2-5 | 본판 자원 가치: 돈 1.5, 광석 5, 지식 5, 토큰 0 또는 4, 정보 8, 행성 8충전. 4파워 액션은 비슷한 효율, 7파워 3지식은 그저 그럼, 2테라 파워 액션은 꼭 필요할 때만 | (확장판 LF01 값으로 대체) |
| B2-6 | 지식의 실제 가치는 광석과 비슷. 1지식으로 4지식이 완성돼 이번 라운드 진보가 되면 프리 액션도 나쁘지 않음 | ✗ 짝수/4지식 완성 조건 없음 |
| B2-7 | 정보 큐브는 가이아 입성·사거리·정보 액션 모두 효율적. 가이아 점수 라운드에 가이아 입성에 쓰면 최고(큐브당 3–4점 + 행성) | ✗ |
| B2-8 | 라운드 수가 적어 수입에 매달릴 필요 없음(3연방 가능한 수준까지만). 다음 라운드 광산당 2점 보너스면 광산을 미룸. 매 라운드 자원을 다 쓸 필요 없음 | ✗ |
| B2-9 | 보통 3.5연방 분량 자원 → 3연방이면 일찍부터 비효율적 행동으로 점수화 | ✗ |
| B2-10 | 건물 수입: 광산 1광석(5충전), 교역소 3.5돈(5), 연구소 1지식(5), 의회 4충전+1토큰(4 또는 8), 지식 아카데미 2지식(10), 정보 아카데미 1정보(8, 짓는 라운드 1정보 즉시라 지식 아카데미와 비슷) | △ 수입표(income.json)로 수입 자체는 정확 |
| B2-11 | **광산은 항상 2개 유지**(아카데미+광산 오프닝 제외). 세 번째 광산은 수입 0 → 가능하면 빨리 넘어가 광산 뿌리기. 2광산 2교역소 vs 6광산이면 6광산이 수입 큼(사거리 2 필요) | △ 수입표는 맞음, 전략 미반영 |
| B2-12 | 광산을 많이 낀 연방은 웬만하면 선언하지 말 것. 가장 싼 연방은 **교역소×3+광산** | ? federation/ |
| B2-13 | 교역소 업그레이드는 수입 가치상 비효율. 돈·광석 균형, 연방 각, 라운드 보너스, 파워 받기 위한 유틸. 연방 티어 상승 목적이면 가장 효율적 건물(6R엔 교역소를 많이 지음) | ✗ |
| B2-14 | 교역소→연구소는 상당히 효율적(기술 타일). **다음 라운드 지식이 짝수가 되도록**. 연구소는 의회와 같은 연방에 묶이지 않게(나중에 아카데미 티어 활용) | ✗ |
| B2-15 | 의회: 비싸고 수입 총량은 늘지 않음 → **능력이 필요할 때만**. 1R엔 보통 의회보다 연구소(네블라·테란·기오덴·아이타·란티다는 비슷) | ✗ (BGG 오프닝으로 간접) |
| B2-16 | **지식 아카데미 1개가 연구소 2개보다 효율적**. 1–3R 지식 아카데미, 5–6R 정보 아카데미 | ✗ |
| B2-17 | 큰 건물 4티어 기술이 있으면 의회·아카데미가 교역소·광산만큼 효율적인 티어 수단 | ✗ |
