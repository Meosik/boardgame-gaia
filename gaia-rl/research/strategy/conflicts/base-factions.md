# 기본 종족 자료 충돌표 (테란·란티다·제노스·글린·타클론·앰바스·기오덴·발타크·하이브·매드안드로이드·네블라)

작성 2026-10-20. 근거: `faction-claims-status.md` + `claims-new/*.csv` 행 원문(BGG-O1-O2, PG06/10/22/25, B16-B17, SH04-SH05, MISC 확인). CSV는 수정하지 않음.

읽는 법
- 다룬 범위: 자료끼리 **판단이 엇갈리는** 것만. 1R 오프닝(PI/AC/RL), PI 시점, 첫 연구·트랙 우선순위, 기술 타일, 연방 수·시점.
- 약어: PI 의회, AC 아카데미, RL 연구소, TS 교역소, M 광산(BGG 표기는 R1 종료 보유 수, 시작 광산 포함). n = BGG-O2 4인 전체 게임 수, 점수 = 평균 점수(승률 아님).
- 근거 순위: BGG-O1/O2 통계(판본 기본, 신뢰도 상, 종족당 1500~2000판, HS는 종족당 약 100판) > PG 팟캐스트(기본, 대부분 상) > B 블로그(기본, 중~상) ≈ MISC(IRIS, 기본, 중) > SH(LF, 중). 같은 급이면 **LF 자료가 우선**: 이 프로젝트는 항상 LF, 1R부터 연방 가능.
- 판정: **조건부** = 조건만 정하면 자료가 서로 맞음. **미해결** = 우리 A/B 필요. A/B 판정 기준은 1–3R 충전 수(`charge_rounds.py`)이고 최종 점수가 아님.
- 교사 열: 19열 기준. Y기 = Y(기준, 배포 교사), Y실 = Y(실험 교사), N = 반영 안 됨. 오프닝 행의 Y기는 "1R 오프닝 후보 순서(순서만)"에 들어갔다는 뜻. 실제 순서는 코드에서 확인하지 않음.

가장 큰 충돌 3개
1. **트랙 순서: 교사(B 블로그) vs PG 상급 자료.** 네블라: 교사는 경제 먼저(B8-02 Y실), PG10-S18/S19(상)는 과학 먼저이고 경제 먼저는 "함정"이라고 봄. 란티다: 교사는 항해 2 먼저(B16-02 Y실), PG06-S04/S12(상)와 LF 1판 경험(PG25-S07)은 경제 2 먼저이고 1R 항해는 "완전히 틀림"이라고 봄. 하이브도 같은 모양: 교사는 경제 2(B12-02 Y실), PG22-S14/S16(상)은 과학 먼저.
2. **LF 1R 연방 PI vs BGG 기본판 통계.** SH04(LF)는 "1R 기술연방을 먹을 수 있을 때만" PI+TS 계열을 2순위로 둔다(테란 S18, 제노스 S33, 매드 S41). 반면 BGG 기본판에서 1R PI는 제노스 -30점, 매드 PI+2M 107점(n=8)이다. LF에서는 1R 연방이 가능하므로 기본판 통계를 그대로 옮길 수 없다. 우리 A/B가 필요함.
3. **1R 오프닝: 교사 후보 1순위와 BGG 최고 점수가 다름.** 테란: 교사는 PI+2M(T06, n=894, 148점). RL+4M은 n=129, 160점, HS에서는 셋이 비슷함. 매드: B13-03 기본 오프닝 RL+TS+2M은 n=124, 136점이고 RL+4M은 145, RL+5M은 150. 타클론: AC+2M(n=549, 160점) vs 2RL+2M(n=59, 168점).

## 교사 영향 정리 (현재 반영 행과 부딪히는 것)

- **배포 교사 Y(기준)**: T1(테란 PI+2M 우선), X1(제노스 LF 1R PI 후보), X5, G1(글린 TS+5M), K1, A1, E1, E2, M1(RL+TS+2M 포함), M2, N2. 대부분 "오프닝 후보 순서"라서 BGG 고득점안(테란 RL+4M, 매드 RL+5M, 타클론 2RL+2M, 앰바스 RL+5M)이 앞에 있는지 코드에서 확인해야 함.
