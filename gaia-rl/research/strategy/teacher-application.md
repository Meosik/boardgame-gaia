# 교사 적용 대조표 — 2026-09-15

## 사용자 확인용: 지금 코드에 들어간 것과 아직 빠진 것

**기준:** “입력해 놓은거 다시 적어놔 확인할거야” 요청 시점의 실제 코드.
아래가 과거 절의 포괄적인 ‘반영’ 표현보다 우선한다. **자료 정리, 탐색 후보 구현,
실제 대국에서의 선택, PPO 가중치 학습은 서로 다른 상태다.**
현재는 종족별 대표 건물/능력 경로까지 연결돼 있으며, 제공 공략의 기술·트랙·부스터
추천을 전부 연결한 상태가 아니다. 그 누락을 보완하는 작업 도중 작성한 확인표다.

### 1. 현재 실행 경로에 들어간 공통 내용

- **18종족 실제 프로필:** 고향 행성, 시작 건물, 종족별 수입과 고유 행동의 실제 엔진 결과를
  사용한다. 다른 종족으로 위장해 평가하지 않는다. 모든 종족에 별도의 완성된 전문가 정책이 있다는 뜻은 아니다.
- **기본 14종족 BGG 오프닝:** Part 2의 222개 행을 종족별 R1 종료 시 현존 건물 조합 후보로
  사용한다. 시작 광산을 포함하고, 지었던 건물의 누계가 아니다. 맥락에 맞는 목표를 선택하고
  검증된 경로가 있으면 유지/전환하며, 찾지 못하면 기존 판단으로 진행한다. R2부터 이 조합 유도를 끝낸다.
  자료의 사용 횟수·평균 최종 점수는 **승률이나 추가 학습 보상으로 바꾸지 않았다.**
- **성장/확장 비교:** 큰 건물, 연구 진보, 가이아/초차원 개척, 고급 기술, 연방 경로를
  실제 자원 지출과 두 수입 경계까지의 결과로 비교한다. 최초 4종족은 코어 전략에 광산 1~2개를
  먼저/나중 늘리는 대안도 있다. 현재 시간 안에 모든 후보를 끝까지 살핀다는 보장은 없다.
- **함선:** 리벨리온 기술/교역소, 트와일라잇 거리 건설/연구소/연방 토큰 재사용/유물,
  TF마스 크레딧 테라포밍/가이아 포밍, 이클립스 소행성 광산/연구의 입장→사용 경로를 비교한다.
  이름만 목표에 올렸다고 입장비나 사용비를 면제하지 않는다.
- **연방/기술 선점:** 독립 코어 3연방을 노리는 대안과 조기 연방→고급 기술 대안을 비교한다.
  아이비츠는 여러 독립 연방 대신 단일 연방 확장으로 처리한다. 3연방 달성을 규칙으로 강제하지 않는다.
- **기술·부스터 일반 평가:** 현재 합법 선택의 실제 수입/득점/효과 평가는 있다.
  그러나 이것은 ‘그 종족에게 추천된 특정 기술을 미리 준비해 취득하고 후속 행동까지 연결’한 것과 다르다.
- **기존 보존 제약:** 광석→크레딧, 지식→크레딧 제한과 목적이 증명된 좁은 QIC→광석 예외,
  타클론 브레인스톤 가이아 금지를 유지한다. 게임의 인간 행동 규칙 자체를 바꾸지 않는다.
- **탐색 한계:** 의사결정당 기존 60초 soft / 300초 hard, 두 수입 경계,
  최대 192결정과 제한된 자금 조달 미리보기를 유지한다. 미탐색은 불가능/열등 판정이 아니다.

**공통 구현 누락도 확인됨:**
1. 특정 표준 기술을 목표로 삼아 유료 건물/함선 준비부터 이어가는 `technology` 목표가 아직 없다.
2. `scoring_pairs`는 기존 `sequence`의 직접 하위 목표만 보므로 새 `ordered`/중첩 수순과 득점 기술 연결이 빠져 있다.
3. 새 순차 수순에서 기술 취득 시 무료 연구 진보를 뒤의 연구 목표와 맞추는 연결도 빠져 있다.
4. 이타르 등 특수 기술 선택 형태와 연구판에 고정된 기술의 실제 진보 트랙을 공통 연결에서 빠짐없이 처리해야 한다.
5. 종족별 부스터 추천을 실제 다음 라운드의 비용 지불 가능한 후속 계획과 연결해야 한다.

### 4. 확인 시점의 작업/검증 상태

- 이번 보완의 회귀 테스트 초안 `faction_teachers/test_guidance.py`만 추가된 상태다.
  아직 없는 `guidance` 모듈 때문에 import 단계에서 실패한다. **7개 테스트 통과나 구현 완료가 아니다.**
- 앞선 115개 통과 기록은 기존 공통 교사/기록 연결 검증이다. 위 누락 보완의 통과 증거로 재사용하지 않는다.
- 이번 ‘공략 전부 보완’ 버전의 완전한 교사 대국은 아직 시작하지 않았다. 기존 단일 결정 진단과 구분한다.
- 사용자 제공 자료는 보존 요약과 현재 가용 SRT/BGG PDF를 활용한다. 기존 PDF 24개 원본 경로는
  현재 미가용이며, SRT 26편의 전 문장·원음을 전수 검토한 상태는 아니다. 티어/경매/하우스 룰은
  종족 보너스나 게임 규칙으로 이식하지 않는다.
- 이번 확인 요청에 대한 변경은 이 대조표와 기존 계획의 상태 기록이다. 게임 규칙·교사 정책·PPO 모델은 변경하지 않는다.

### 5. 후속 사용자 보충: 확장 4종족의 시작 위치

- 사용자: “확장 종족 엥간하면 인터스페이스에 있는 원시/소행성에서 시작하는 편이지 확장을 위해서”.
  기록한 의도는 **이후 확장을 위해 대체로 인터스페이스의 자기 고향 행성을 선호**한다는 것이다.
  무조건 해당 구역에 고정하거나 다른 합법 시작점을 삭제하라는 지시는 아니다.
- 현행 native 고향: 모웨이드·스페이스자이언트는 원시 행성(`ProtoPlanet`),
  팅커로이드·다카니안은 소행성(`Asteroid`). 시작 배치는 자기 고향 유형만 합법이다.
  두 유형을 모든 확장 종족이 자유롭게 고르는 전략으로 오해하지 않는다.
- 현재 `four_factions.value.placement`는 근거리 고향 행성, 이웃, 함선 거리 등을 평가하지만,
  **인터스페이스 시작점을 명시적으로 선호하는 종족별 경로는 아직 없다.**
  향후 보완에서 실제 후속 확장 가능성을 비교해야 하며, 이번 기록만으로 새 수치 가중치나
  강제 배치를 구현했다고 표시하지 않는다.

### 6. 후속 시간 배분 변경

사용자는 기본 목표10초, 교사마다 한 판당 최대120초 긴 고민6회를 필요할 때 자동 사용하는
방식과 ‘계획 수립은 오래, 이미 정한 수순 실행은 빠르게, 결론이 나면 조기 종료, 가짜 대기 없음’을
승인했다. 새 `--adaptive-clock` 실행 경로에 적용하며 기존60/300 대조 경로는 남긴다.
이 변경은 위 기술/트랙 공략 누락을 해결한 것이 아니다. 시간 배분의 후보 간 격차/안정성 기준은
실력 검증 전 휴리스틱이다. 현재 교사전은22개 완료 행동과 전략 기억을 보존해 새 시간 설정으로
이어가는 작업 중이며, [실행 계획](../../../.omx/plans/gaia-rl-training-evaluation.md)에 검증 상태를 기록한다.

## 후속 18종족 공통 교사 연결

아래 과거 4종족 기록은 유지한다. 최신 사용자는 공통 엔진+종족별 판단을 승인했고,

기본판 14종족에는 BGG 목표와 확보된 종족별 공략의 조건부 수순을 적용한다.

이전 4종족 기본 실행 경로는 보존하며 새 공통 교사를 명시적으로 선택한다.

표시하지 않는다. 실제 대규모 시범 수집·PPO 학습·자동 모델 승격은 별도다.

## 새 경로의 안전 조건

- 모든 실행은 현재 네이티브 후보 인덱스로 다시 결정한다. 예측 인덱스를 다음 차례에 재사용하지 않는다.
- 선택한 계획은 남은 목표만 기억해 다음 비교의 후보로 올린다. 자동 실행 강제가 아니다.
- 상대가 목표 행성/기술을 가져갔거나 같은 아카데미를 다른 곳에 완성했으면 불가능한 계획을 버린다.
- 광산 목표는 실제 건물 위치 수로 센다. 광산을 교역소로 바꾸었다고 확장 진도가 초기화되지 않는다.
- 함선 사용은 그 플레이어의 실제 행동으로만 달성 처리한다. 다른 플레이어가 사용한 공용 슬롯을 자기 성과로 세지 않는다.
- 건설·수입·득점은 네이티브 전개 결과에만 생긴다. 목표 선언/자료에 나온 추천 자체에는 점수를 주지 않는다.
- 모든 원래 합법 루트는 비교 대상에 남는다. 시간 제한으로 비교하지 못한 루트는 ‘나쁨’이 아니라 ‘미확인’이다.

새 오프닝 전부를 비교하는 것은 아니며, 실제 네 교사만 외부 시간 제한 검색을 각각 수행한다.
CPU/미니PC 분산이나 상대 차례 사전 계산은 사용자의 질문만으로 구현하지 않았다.

### 2026-09-16 승인: 교정 교사의 고정 R1 목표

신규 coaching 설정의 `fixed_openings=True`는 하드쉬·타클론·제노스의 **지식 아카데미1 + 잔여 광산2**, 테란의 **의회1 + 잔여 광산2**를 우선한다. 목표 달성 뒤 추가 행동을 막지 않으며, 기술/연구/부스터/위치를 고정하지 않는다. PPO의 합법 행동이나 native VP/보상에는 적용하지 않는다. 기존 frozen coaching 세션은 자동 전환하지 않는다.

실행: `bgg_openings/fixed.py` → `Policies.rank`/timeout reserve, `TimedPreparationTeacher(fixed_openings=True)`. 실제 비용을 낸 후보 중 코어 진전·부족 자원 확보를 우선하고 무관한 QIC 확장을 보류한다. 최종 코어 기술 선택에서는 남은 광산 비용까지 지불 가능한 변형을 우선한다. R1 종료 시 미달은 교사 utility 3.0 손실(미보정 초깃값, 게임 VP 차감 아님)로 기록/예측한다. 자원 조달이 모두 해결되는 완전 탐색이라고 주장하지 않는다.

소각은 새로 가능해진 파워 소비 행동과 최소 소각량을 확인하며, 이후 그 소비를 수행하도록 목적을 유지한다. 소각→파워 자원 변환→최소 QIC→유료 코어의 짧은 실제 조달 경로도 검증하며 무관한 소각/확장을 막는다. 최종 라운드 자원 정리의 기존 예외는 유지한다. 목표 달성/소각 검증 및 `fixtures/coached-r1.json`, `fixtures/last-mine-budget.json`의 실제 native 회귀는 `bgg_openings/test_fixed.py`에 있다. 한 셋업의 목표 달성은 전반적인 실력 또는 편향 해소의 증거가 아니다.
