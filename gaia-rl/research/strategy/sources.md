### 표를 학습 기준으로 읽을 때 필요한 정의

- **승률 표가 아니다.** BGG-O1은 평균 최종 점수와 해당 건물 건설 비율,
  BGG-O2는 `Openings / Games / Avg Score`다. 선택률·사용 횟수·평균 점수와 승률을 구분한다.
  BGG-O2 9쪽 댓글에서 순위 통계 요청과 저자의 최종 점수 지표 선택 설명도 확인했다.
- BGG-O1은 전체 4인전과 별도 고숙련 4인전(1쪽 본문: 평균 Elo 300 이상)을 구별한다.
  BGG-O2 표는 **전체 4인전**이며 고숙련 전용 표가 아니다. 9쪽 저자 설명의 종족당 약
  1,500–2,000게임은 대략적인 서술이며 각 오프닝의 표본 수로 쓰지 않는다.
- BGG-O2는 적어도 5회 사용된 오프닝 중 대체로 인기 상위 15개를 표시한다.
  일부 종족 표는 더 길다. 표에 없는 조합을 불법/불가능/승률 0으로 해석하지 않는다.
- **BGG-O1은 R1 중 건설한 이력**, **BGG-O2는 R1 종료 시 보유한 건물 조합**이다.
  따라서 Part 1에서 `1AC + 1RL`은 보통 RL을 거쳐 AC로 업그레이드한 이력이며,
  종료 시 AC와 RL을 각각 보유했다는 뜻이 아니다. Firaks 강등과 Bescods 건설 경로도 구별한다.
- Part 2의 `M`은 시작 광산을 포함해 종료 시 남아 있는 광산 개수다.
  Ambas의 `RL + 5M`은 시작 광산 2개에서 **광산 4개를 추가 건설**하고 하나를 RL로 올린 결과다.
  1쪽 수정 본문과 9쪽 정정 댓글이 일치한다. 새 광산 5개 건설 목표로 바꾸지 않는다.
- 두 글은 구체적인 모든 행동 순서·배치 좌표·연구 경로를 제공하지 않는다.
  Part 2는 지식 아카데미와 QIC 아카데미도 분리 집계하지 않는다.
- 본문에는 번역 오류가 있다(예: AC를 항공기 기지, RL을 로켓 발사대, M을 금액으로 번역).
  영문 표 기호와 게임 엔진의 건물 의미를 기준으로 읽는다. 공략의 자원 수치를 엔진 규칙보다 우선하지 않는다.
- **2021년 기본판 14종족 자료**다. Tinkeroids/Moweyds/SpaceGiants/Darkanians 및
  Lost Fleet 함선 환경의 검증된 오프닝 통계로 확장하지 않는다.

### 후속 표 전사와 판정 코드 — 2026-09-15

사용자 구현 승인 후 Part 2의 나머지 10개 종족 표 이미지도 직접 확인했다.
이제 **14개 표 전체의 222행**을 [bgg-openings-part2.csv](bgg-openings-part2.csv)에 옮겼다.
원문의 행 순서·게임 수·평균 점수·PDF 쪽/행 번호를 보존했다. 위의 일부 수치 예시는 그대로 유지한다.
모든 행을 보존한 것이며, 낮은 표본이나 평균 점수 행을 임의로 제거하거나 승률로 환산하지 않았다.
이 CSV가 공개 원시 대국 데이터나 통계적 인과 검증을 대신하지는 않는다.

`gaia-rl/experiments/bgg_openings/`는 이 표를 읽고 다음 의미를 검증한다.
- 종족과 종료 건물 조합이 정확히 일치하는지 판정한다. 추가 TS/RL이 있는 상태를 더 작은 조합의 달성으로 취급하지 않는다.
- 시작 광산을 다시 더하지 않고, 아카데미로 올라간 RL이나 강등된 Firaks의 RL을 현존 건물로 중복 계산하지 않는다.
- Science/Qic 아카데미를 표와 같이 합산한다. Ivits의 시작 PI는 현존 PI로 세며 위성/우주정거장은 이 표의 건물 항목에 포함하지 않는다.
- 실제 R1→R2 경계의 마지막 R1 상태를 판정하며, 나중 R2에 달성한 조합으로 R1 결과를 보완하지 않는다.
- 자료가 없는 확장 종족의 조합을 생성하지 않는다. 판정 함수 자체는 네이티브 기보 검증이나 교사 정책이 아니다.

확인: 새 단위/네이티브 테스트 11개 통과. 실제 네이티브 R1 경계 테스트가 14개 자료 종족을 모두 포함한다.
후보 선택/전환/대체 정책은 사용자 답변 대기 상태이며, **교사의 실제 행동 강제·PPO 연결·추가 학습은 아직 미적용**이다.

### 사용자 승인 후 교사 연결 — 2026-09-15

후속 “그렇게 해”로 위의 대기 선택이 확정됐다. **상황에 맞는 조합 선택 → 가능한 목표 유지 →
다른 BGG 조합으로 전환 → 확인된 경로가 없으면 기존 교사 판단**으로 처리한다.
`bgg_openings/planning.py`와 기존 `four_factions` 준비 수순 탐색을 연결했으며,
`four_factions.compete --bgg-openings`로 명시적으로 켠다. 기본 교사 동작은 유지한다.

목표의 실현 여부는 실제 비용을 지불하는 네이티브 예측의 R1 종료 건물로 확인하고,
서로 비교할 때는 기존의 두 번 수입 이후 평가값을 그대로 사용한다. 표의 평균 최종 점수를
추가 보상으로 주거나 승률 가중치로 바꾸지 않는다. 제한 시간 내 탐색하지 못한 경로는
‘불가능’이 아니라 ‘미확인’이며, R2부터는 기존 운영으로 돌아간다. 실제 대국의 R1 결과는
예측과 별도로 기록하고 CSV도 실행 당시 소스 해시에 포함한다.

현재 실행 연결은 기존 교사가 있는 Xenos/HadschHallas/Terrans/Taklons 네 종족이다.
14종족 표와 판정 지원을 14종족 교사 완성으로, 이 연결을 PPO 학습 완료로 표시하지 않는다.
실제 네이티브 테란 테스트에서 조기 패스 대신 자원을 지불한 업그레이드로 `1RL+1M`을
달성하고 독립 재실행 결과가 일치했다. 전체 대국 점수 개선이나 확장판 환경의 통계적
타당성은 아직 검증하지 않았다.
