# 교사 자체 대국 vs 어잌후 관전 기보 — 어디서 점수가 빠지나 (2026-10-18)

사용자(2026-10-18): "관전 마지막에 뭘로 몇 점 벌었는지도 나오는데 리플레이랑 비교해서 어느 부분이 떨어지나 봐도 되고".
새 도구 `tools/game_profile.py`가 lab 6R 판을 관전 기보와 같은 항목으로 읽는다(좌석별 차례 수·건물·기술·연방·가이아·함선·
아티팩트, 그리고 **점수를 얻은 수의 종류별 VP**). 엔진 스냅샷에 VP 사유 로그가 없어 VP는 "그 점수를 낸 수"에 귀속한다
(패스 = 부스터 패스 점수, 건설·업그레이드 = 라운드 타일, 연방 = 토큰, 함선 입장·충전 = 비용, 게임 끝 = 연구 4점/단계 + 미션·잔여).

비교 대상
- 사람: [어잌후 4인 Lost Fleet 관전 1판](observed-uiqoo-20260916.md) — 발타크 147·아이비츠 131·타클론 74·파이락 72(최종 계산 전).
  **한 판**, 종족이 다르고(발타크·아이비츠·타클론·파이락) 타일 종류 미상. 아이비츠 상세 점수창만 항목별 숫자가 있다.
- 교사: lab 060 A팔 = 기준 스택 vm_lf_ts_ships, 6R 끝까지, 시드 6개 × 좌석 교대(종족당 6좌석), 4AI 자체 대국. B팔(when_all_tech_fix)은 참고.

## 2. 점수를 낸 수의 종류별 VP (좌석당 평균)

| 종류 | 아이비츠(사람, 상세 점수창) | 교사 ships Geo / Tak / Ter / Xen |
|---|---:|---|
| 부스터(패스 점수) | 17 | 3.2 / 8.5 / 10.3 / 16.0 |
| 연방 토큰 | 16 | 7.0 / 6.5 / 7.2 / 16.7 |
| QIC 액션 | 15 | 0.7 / 2.3 / 0.3 / 1.5 (액션·변환 전체) |
| 고급 기술 | 16 | ≈0 (고급 타일 0.2–0.7개) |
| 아티팩트 | 12 | 2.8 / 0 / 0.7 / 0 |
| 연구(끝 4점/단계) | 24 | 21.3 / 21.3 / 26.0 / 26.0 |
| 최종 목표(미션) + 잔여 | 27 | 28.0 / 18.0 / 25.5 / 24.0 |
| 라운드 타일(건설·업그레이드로 얻은 VP) | (항목 없음) | 12.4 / 6.7 / 9.3 / 21.2 |
| 함선 행동 | (QIC 액션에 포함) | 6.5 / 3.5 / 9.0 / 21.2 |
| 함선 입장 비용 | −10 | −13.3 / −7.5 / −11.7 / −15.0 |
| 충전 비용 | −17 | −2.7 / −6.7 / −3.5 / −5.7 |

읽기
- **연구 끝점수와 최종 미션은 사람과 비슷하다.** 차이는 거의 전부 **보드 위 경제**에서 난다: 광산 1/3, 교역소·연구소 거의 없음,
  차례 수 60–70%. 건물이 없으니 연방(절반), 라운드 타일 점수, 파워·지식 수입이 같이 빠진다.
- **고급 기술 0, QIC 액션 ≈0, 아티팩트 ≈0** — 사람 아이비츠는 이 셋에서 43점. 교사는 고급 기술을 집는 수가 아예 안 나온다
  (기준 스택의 고급 기술 규칙은 when_all_tech 묶음(adv_immediate 등)에만 있음).
- 충전 비용은 사람이 더 많이 낸다(−17 vs −3~−7): 사람은 파워를 받으려고 점수를 쓰고, 교사는 리치를 자주 거절한다.
  함선 입장 비용은 비슷하다.
- B팔(when_all_tech_fix)은 Geo·Tak 점수가 올랐는데 라운드 타일(업그레이드 12–15)과 패스 점수가 오른 대신 1–3R 충전이 떨어졌다(060 판정).

## 3. 결론 — 떨어지는 부분의 순서

1. **차례 수와 광산**: 일찍 패스하고 광산을 안 짓는다(타클론 한 판 2개). 2R 교역소가 "손해"로 매겨지는 가격표·지평선 문제와 같은 뿌리.
2. **고급 기술·QIC 액션·아티팩트**: 중반 이후 점수 엔진이 없다(사람 43점 vs 교사 ≈3).
3. **연방 수**: 건물이 없어서 따라오는 결과.
4. 연구·미션은 이미 사람 수준이라 더 올릴 여지가 작다 — 여기에 규칙을 더 넣는 것은 효과가 적다.
