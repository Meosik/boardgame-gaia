# 교사 스택 부품 목록 (2026-10-19, 기준 스택 = vm_lf_ts_ships)

코드: `tools/teacher_patches.py`(팩토리 체인과 `_guide` 플래그 표, 527행), 값표 `tools/guide_value.py`.
팩토리 이름은 체인 순서대로 길어진다: symmetric_pass → geodens_guide → guide_values → guide_values_openings
→ guide_values_openings_free → guide_r1 → guide_r1_charge3 → _lf → _lf_tiles → _lf_more → _vm → _vm_lf → _vm_lf_ts
→ **_vm_lf_ts_ships(기준, 실서버 D1이 배포할 교사)**. 그 위의 opt-in은 기준 스택 함수를 부른 뒤 install_*()·플래그를 더한다.
"순서만" = 값·계수를 더하지 않고 후보 순위나 비교 집합만 바꿈(비교가 결정). "값" = 상태 가치 식 자체를 바꿈.

## D. 종족별 편입에서 손댈 곳

- 이미 종족 조건이 코드에 있는 부품: 2(기오덴), 4(라벨 표), 7②(테란)·⑥(기오덴), 14 일부, 18(타클론), geodens_b14_tech, academy_economy(발탁 제외), track_income(단 표).
- 종족 조건이 없는 부품(former_use, opening_budget/guard/release, research_when_land, label 계열)은 install_*() 또는 *_scores()에 종족 집합 인자를 더해야 한다(순서·범위만, 수치 없음).
- 제안하는 형태: 팩토리 `..._ships_byfaction` 하나 + 종족 → 부품 집합 표 한 개(근거 사이클 번호 주석), 미측정 종족은 빈 집합(= 기준 스택 그대로).
