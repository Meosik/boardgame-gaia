# 조건부 시범 전략 비교 (실험 전용)

사용자 승인 범위: **제노스·하드쉬할라**, 공략 기반 시범학습 유무를 짧게 비교.
게임 규칙·최종 점수 보상·기존 학습 기본값·서버/UI는 변경하지 않는다.

## 실행

```sh
cd gaia-rl
OMP_NUM_THREADS=2 PYTHONPATH=experiments .venv/bin/python -m unittest discover -s experiments -p 'test_strategy_teacher.py' -v
.venv/bin/python experiments/strategy_pilot.py --output runs/strategy-pilot-v1
```

기존 출력 경로는 거부한다. 명시적으로 실행해야만 시뮬레이션/학습을 시작한다.
환경/인코더는 기존 네이티브 빌드와 소스 일치 검사를 그대로 사용한다.
공략 출처는 [전략 자료](../research/strategy/README.md) 참고.

## 비교 방법

- 엔진의 합법 후보 중에서만 고르는 조건부 교사. 초기 광산 배치부터 실제 6라운드 종료까지 진행한다.
- 공략에서 가져온 방향: 확장/충전 위치, 자원 부족 해소, 준비된 함선 후속 행동, 연구 시점·경쟁, 위성 절약.
- 아티팩트 수입과 즉시 보상은 별도로 평가한다. 초반 의회 금지나 정해진 연구 순서를 강제하지 않는다.
- 숫자 우선순위는 **검증되지 않은 실험 가설**이다. 게임 규칙이나 추가 보상이 아니다.
- 양 종족을 포함하는 시드를 찾되, 맵 품질이나 결과를 보고 선별하지 않는다. 다른 종족은 기존 선택 방식 그대로다.
- 시범 6게임/검증 2게임을 분리. 교사가 두 대상 종족을, 무작위 합법 정책이 나머지를 플레이한다.
- 두 PPO 정책은 같은 초기 가중치·새 옵티마이저·학습 시드/환경 풀·PPO 예산에서 시작한다.
  실험군에만 먼저 행동복제(BC) 4 epoch를 적용한다. 1개 후보뿐인 강제 선택과 미지원 선택은 학습 표본에서 제외한다.
- 각 군 PPO 4회 × 256 설정 배치. **BC 계산량은 추가**이므로 총 계산량까지 맞춘 우열 실험은 아니다.
- 평가에서는 교사 개입 없이 학습 정책만 사용한다. 교사 자체 평가는 별도로 기록한다.
- 대상 종족을 각 좌석에서 한 번씩 평가하는 4개 맵을 사용한다. 제노스 다음 좌석에 하드쉬할라가 있는 배치로 균형을 맞춘다.
  이는 **동일 맵의 좌석 회전이 아니라 좌석별 서로 다른 맵**이다. 각 군 8게임, 교사 별도 8게임이며 상대 셋은 무작위 합법 정책이다.
- 모든 실패 게임은 보고서에 남긴다. 실패가 있으면 완료 게임 평균만으로 개선을 주장하지 않는다.

## 산출물·한계

`manifest.json`: 버전·실험 파일 해시·시드/종족/예산.
`demonstrations.jsonl.gz`, `validation.jsonl.gz`: 판단 시점 스냅샷·선택·근거.
`imitation.json`: 학습/검증 손실과 정답 일치율.
각 군 `inference.pt`, `training.json`: 추론 가중치와 PPO 진단.
`*_evaluation.json`, `report.json`: 전체 게임별 완주/승점/행동/라운드 시작 상태와 요약.

- 추론 전용 가중치다. 기존 `OfflinePolicy`/`restore_run`에 넣는 운영 체크포인트가 아니며 옵티마이저 재개를 지원하지 않는다.
- 기존 모델과 학습 기본 설정은 수정하지 않는다. 실험 소스 해시는 기존 Python 패키지 지문과 별도로 기록한다.
- 부스터는 간단한 동점 해소 순위이며, 실제 패스 점수·전체 고급 기술 카운터·모든 건설 비용을 계산하는 장기 탐색기는 아니다.
- 교사는 완전한 종족 공략 구현이 아니라 제한된 시범 생성기다. 두 대상 외 종족에는 교사 라벨이 없지만 공유 PPO에는 그들의 경험도 들어간다.
- 소수 게임·무작위 상대 결과다. 인간 수준, 확장 최적 전략, 장기 학습 효과를 입증하지 않는다.

## 첫 실행 결과 — `runs/strategy-pilot-v2`

**실행은 성공했지만, 시범학습에 따른 성능 개선은 실패했다.** 기존 저장 모델이 아니라
동일 초기값에서 시작한 일반 PPO와 비교했다. 종족별 각 4게임, 상대는 무작위 합법 정책이다.

| 정책 | 제노스 평균 VP | 하드쉬할라 평균 VP | 제노스 승리 지분 | 하드쉬할라 승리 지분 |
|---|---:|---:|---:|---:|
| 일반 PPO | 66.50 | 52.50 | 100% | 50% |
| 시범학습 + PPO | 35.25 | 37.25 | 0% | 25% |
| 교사 전략 직접 실행 | 76.50 | 79.25 | 75% | 100% |

- 시범 6게임 + 검증 2게임 완주. 학습 표본 810개(제노스 418, 하드쉬할라 392), 검증 239개.
- 검증 교사 선택 일치율 23.01% → 33.47%, 교차엔트로피 2.2316 → 1.9890.
  모방 정확도 상승이 실제 점수 상승을 보장하지 않음을 확인했다.
- 평가 24/24게임 완주: 각 PPO 정책 8게임 + 교사 8게임. 실패 게임을 제외한 선택적 평균이 아니다.
- 두 군 모두 네이티브 환경 1,024 step. RLlib 모듈 표본은 종료 처리 차이로 1,042/1,039개다.
  BC는 추가 408 gradient step이며 총 계산량을 맞춘 비교라고 주장하지 않는다.
- 수정 후 전체 실행 약 239초. 앞선 시드 검색/실패 실행/단위 검증 시간은 포함하지 않는다.

### 관측과 미확정 원인

평가 4게임 합산에서 제노스의 `ResearchAdvance`는 일반 PPO 8회, 시범학습 3회,
교사 12회였고 `FormFederation`은 각각 4/0/4회였다. 하드쉬할라의 연방 형성은
3/1/6회였다. **시범학습 모델이 연구와 연방을 충분히 재현하지 못한 것은 관측 사실**이다.
왜 그런지(적은 표본·학습량, 상황 분포 차이, 표현력, PPO 간섭)는 아직 분리 검증하지 않았다.
공략이 틀렸다는 결론이나, 학습을 오래 하면 반드시 해결된다는 결론은 내리지 않는다.

다음 실험 후보는 득점으로 이어지는 희소 분기의 표본 보강과 BC만 적용한 정책의 별도 평가다.
이번 결과를 보고 대규모 학습 또는 서버 적용으로 자동 진행하지 않았다.

### 검증·이력

- 기본 조건 검증 12개 통과. 첫 시범 중 고급 기술 선택에 `tile` 필드가 없다는 처리 누락을 발견해
  수정했고, 추가 회귀 검증 및 조기 의회 선택 검증 2개가 통과했다(서로 다른 검증 13개).
- `runs/strategy-pilot-v1/failure.log`에 실패 원인을 보존했다. v2는 그 실행의 시드 목록을 재사용했고,
  엔진 버전·종족 구성·분리된 시드·평가 좌석 균형을 재검증했다. 기존 결과를 덮어쓰지 않았다.
- 추론 가중치 재로딩·유한값·초기 합법 선택, 실험 파일 해시, 엔진/패키지 지문, 로그 선택 인덱스 확인.
- 실험 코드만 추가하고 기존 게임/학습 코드·규칙·보상·서버는 변경하지 않았다.
